키움증권 주식 자동매매 설정 방법

트레이딩뷰 얼러트가 발생하면 TVExtBot이 키움증권 계좌로 주문을 보내는 방식입니다. 아래 순서대로 API키 연결 → 주문메시지 작성 → 얼러트 설정을 진행해 주세요.

바로 찾기: 지원 범위 · 설정 순서 · 장외 거래 · 시장가·지정가 · 자동 취소 · 문제 해결

먼저 확인하세요

거래 대상주문 방식장외 거래
국내 주식: 코스피·코스닥시장가·지정가실전 계좌의 NXT 지원 종목만 가능
미국 주식: 나스닥·뉴욕·아멕스시장가·지정가TVExtBot의 장외 거래 옵션 미지원
모의투자: kiwoom-testnet국내 주식 시장가·지정가NXT·미국 주식 미지원

주문수량은 주식 수, 주문가능 잔액·수량 대비 %, 총자산 대비 % 중에서 설정합니다. amount: 1은 1주이며, 매도할 때 주문에 묶인 수량은 주문가능수량에서 제외될 수 있습니다. 수량 입력 방법

1. API키 연결부터 얼러트 설정까지

  1. API키 발급·등록: 거래소 API 발급 방법의 키움증권 항목을 펼쳐 신청부터 IP·계좌 등록, 키 발급, 확장프로그램 등록까지 진행합니다. 모의투자 연결 방법도 같은 항목에 있습니다.
  2. 메시지 작성: 거래소·계좌·종목 → 매수/매도·주문유형 → 수량을 입력합니다. 국내 NXT를 쓰려면 아래 장외 거래도 설정합니다.
  3. 트레이딩뷰 연결·결과 확인: 만든 메시지와 웹훅 URL을 얼러트에 넣고, 실행 후 TVExtBot 주문내역·에러 메시지와 증권사 체결내역을 확인합니다. 얼러트 설정 순서

2. 정규장 밖에서도 주문하려면

「메시지 작성」 → 실행 조건 → 장외 거래를 켭니다. 주문메시지에는 "extended_hours":true가 들어갑니다. 아래 시간은 모두 한국시간입니다.

시장주문 시간알아둘 점
국내 NXT 프리마켓08:00–08:50실전 계좌·NXT 지원 종목만
국내 NXT 애프터마켓15:30–20:00주문은 15:30부터, 체결은 15:40부터

미국 주식에는 적용하지 않습니다. 키움의 「장외 거래」 체크는 실전 국내 주문에서만 사용할 수 있습니다. 키움 미국 주문은 기존 주문 경로로 처리합니다.

  • 정규장에는 기존 주문 방식으로 처리합니다.
  • 모의투자에서는 장외 거래를 사용할 수 없습니다.
  • NXT 미지원 종목은 주문하지 않으며, KRX 장외시장으로 자동 전환하지 않습니다.
  • 휴장·거래정지·증권사 운영 조건 때문에 주문이 거부될 수 있습니다.

① 장외 거래 켜기 ② 미체결 자동 취소 시간. 실제 화면 소스로 만든 설정 예시입니다.

3. 시장가와 지정가는 어떻게 다른가요?

주문할 때 선택실제 처리
국내 정규장 시장가기존 시장가 주문
국내 NXT 시장가1호가 기준 시장성 지정가로 제출
미국 시장가키움 미국 시장가 주문으로 제출
지정가지정한 가격 또는 LAST·BID·ASK 기준 가격으로 제출

시장성 지정가는 바로 체결될 가능성을 높이기 위해 매수 가격을 조금 높게, 매도 가격을 조금 낮게 지정하는 방식입니다. 그래도 가격이 범위를 벗어나면 미체결로 남을 수 있습니다.

  • 허용 폭: 0–5%, 비워 두면 0.5%. 매수는 매도 1호가에 더하고, 매도는 매수 1호가에서 뺍니다.
  • 주문을 보내지 않는 경우: 1호가 미수신, 매수·매도 호가 차이 2% 초과. 국내 시장성 지정가는 상·하한가를 못 받아도 주문하지 않습니다.
  • 국내 가격 제한: 시장성 지정가는 호가 단위와 상·하한가에 맞춰 조정합니다.

예를 들어 매수 지정가가 16,530원이어도 더 유리한 호가에서 체결되면 실제 체결가는 16,440원일 수 있습니다. 지정가는 매수 때 지불할 가격의 상한이며, 반드시 그 가격에 체결된다는 뜻이 아닙니다.

① 시장가 선택 ② 허용 폭(예: 0.5%). 장외 거래를 켠 국내 NXT 주문의 설정 예시입니다.

체결가 조회에 성공하면 실제 체결가를 기록하고, 알림에서 지정가와 다를 때 나눠 표시합니다. 조회하지 못하면 지정가로 기록하므로 기록된 가격만으로 체결을 확정하지 마세요. 증권사 체결내역에서 최종 확인할 수 있습니다. 체결가는 주문 직후 한 번만 조회합니다. 그때 미체결이었다가 나중에 체결되거나, 일부만 체결된 뒤 나머지가 체결되면 기록된 가격이 최종 체결가와 다를 수 있습니다.

4. 미체결 주문을 자동으로 취소하려면

「실행 조건 → 미체결 자동 취소」에 1–600초의 정수를 입력합니다. 예를 들어 60초로 설정하면 주문 접수 후 해당 시간이 지난 시점에 남은 수량을 취소합니다. 실제 취소 완료는 처리 상황에 따라 늦어질 수 있습니다.

실전·모의 **일반 지정가(조건주문 제외)**와 실전 국내 NXT 시장성 지정가가 대상입니다. 키움 미국 시장가에는 적용하지 않습니다.

상황처리
전부 미체결남은 주문 전량 취소
일부 체결체결분 유지, 미체결분만 취소
바로 주문·퀵주문자동 취소 옵션 적용 안 됨
취소 실패·상태 확인 실패증권사 앱에서 미체결 확인 및 직접 취소 필요

정상 취소는 **텔레그램 안내(ℹ️)**로만 알려 드리고 에러 메시지 목록에는 남기지 않습니다. 취소 실패·상태 확인 실패는 텔레그램과 에러 메시지 목록 모두에 남습니다.

「미체결 먼저 취소」와 구분해 주세요. 이 옵션은 새 주문 전에 기존 주문을 취소합니다. 반면 「미체결 자동 취소」는 이번 새 주문의 미체결을 나중에 취소합니다. 시장가(시장성 지정가)와 함께 쓰면 기존 주문을 취소하기 전에 호가부터 확인해, 호가 때문에 주문할 수 없으면 기존 주문을 그대로 둡니다. 그래도 취소 뒤 호가가 달라지거나 다른 이유로 새 주문이 거부되면 기존 주문만 취소되고 새 주문은 없는 상태가 될 수 있습니다. 취소 뒤 호가 때문에 거부된 경우에는 오류 안내에 「기존 미체결 주문은 이미 취소됐습니다」가 붙지만, 수량 부족·증권사 거부 등 다른 이유에는 붙지 않습니다. 「미체결 먼저 취소」를 쓴 주문이 실패하면 증권사 앱에서 기존 주문이 남아 있는지 확인해 주세요.

시장가 허용 폭·자동 취소 상세 설명

5. 주문메시지 예시

삼성전자 10주 시장가 매수

TVM:{"exchange":"kiwoom","account":"계좌번호","symbol":"005930/KOSPI","type":"market","side":"buy","amount":10,"token":"인증키"}:MVT

테슬라 보유 수량의 50%를 시장가 매도 (미국 주식)

TVM:{"exchange":"kiwoom","account":"계좌번호","symbol":"TSLA/NASD","type":"market","side":"sell","bal_pct":50,"token":"인증키"}:MVT

모의투자 계좌에서 카카오 5주 지정가 매수 (마지막 체결가)

TVM:{"exchange":"kiwoom-testnet","account":"계좌번호","symbol":"035720/KOSPI","type":"limit","side":"buy","amount":5,"price":"last","token":"인증키"}:MVT

종목은 종목코드/시장 형식입니다. 예시는 형식을 보여 드리기 위한 것이니, 실제 메시지는 반드시 「메시지 작성」 화면에서 만들어 주세요. 각 항목의 뜻은 주문메시지 항목 설명에 있습니다.

주문이 예상과 다를 때

증상먼저 확인할 것
계좌가 연결되지 않음실전·모의 키 구분, 계좌번호, 키 입력값·허용 IP
주문되지 않음「주문 허용」 스위치, 거래 시간·휴장 여부, 주문가능 잔액·수량
시장가인데 지정가로 보임위 주문 방식 표의 시장성 지정가 대상인지 확인
주문 성공인데 미체결지정가 범위 밖인지 확인. 주문 접수 성공은 체결 완료와 다름
자동 취소 안내가 없음얼러트 주문인지, 지원 주문인지, 실제 미체결 상태인지 확인

주문이 안 될 때 확인할 것에서 추가 대처 방법을 볼 수 있습니다.

자주 묻는 질문

Q. 코딩하거나 HTS를 켜 두어야 하나요?
TVExtBot은 증권사 REST API로 클라우드 서버에서 주문합니다. HTS나 사용자 PC를 켜 둘 필요는 없습니다. 트레이딩뷰에서 얼러트를 설정하고 TVExtBot에서 만든 주문메시지를 연결하면 됩니다.

Q. 새 옵션은 기존 얼러트에 바로 적용되나요?
전체 주문메시지를 얼러트에 넣었다면 수정한 메시지를 다시 복사해 반영해야 합니다. 단축 주문메시지(주문ID)를 사용하면 저장된 해당 주문메시지를 수정합니다. 단축 주문메시지 사용법

Q. 다른 증권사와 무엇이 다른가요?
한투·키움 모두 국내·미국 주식과 국내 모의투자를 지원합니다. 국내 NXT도 양쪽 실전 계좌에서 지원합니다. 한투는 미국 시장가 요청을 시장성 지정가로 제출하고 미국 주간거래를 지원하며, 키움은 미국 시장가를 지원하되 TVExtBot의 미국 장외 거래 옵션은 지원하지 않습니다.
