업비트 자동매매 설정 방법 (트레이딩뷰 얼러트 연동)

트레이딩뷰에서 만든 지표·전략의 신호로 업비트 원화(KRW) 마켓을 자동매매하는 방법입니다.
TVExtBot은 클라우드 서버에서 주문하므로 컴퓨터를 꺼 두어도 자동매매가 계속됩니다.

업비트에서 할 수 있는 것

항목내용
마켓원화(KRW) 마켓 (BTC·USDT 마켓은 미지원)
주문현물 매수·매도, 시장가·지정가
주문수량코인 개수, 원화 금액, 잔액·총자산 대비 %
주문가격마지막 체결가, 매수·매도호가, 평균매수가(AVG), 직접 입력

설정 순서

  1. API키 발급: 업비트 PC 웹 → [마이페이지] → [Open API 관리]에서 자산조회·주문조회·주문하기를 체크하고, 확장프로그램 API키 등록화면에 표시된 IP주소를 입력해 발급합니다. → 거래소 API 발급 방법
  2. API키 등록: 확장프로그램 API키 등록 화면의 업비트 줄에 Access키와 Secret키를 입력하고 [연결중] 을 확인합니다.
  3. 주문메시지 작성: 메시지 작성화면에서 거래소를 Upbit 로 골라 매수·매도 메시지를 만듭니다.
  4. 얼러트 설정: 트레이딩뷰 얼러트의 메시지 칸에 주문메시지를, 알림 탭의 웹훅 URL에 본인의 웹훅 URL을 넣습니다. → 웹훅URL에 의한 자동매매

주문메시지 예시

비트코인을 10만원어치 시장가 매수

TVM:{"exchange":"upbit","account":"기본계정","symbol":"BTC/KRW","type":"market","side":"buy","amount":100000,"amount_type":"krw","token":"인증키"}:MVT

평균매수가보다 3% 높은 가격에 보유 수량의 50% 지정가 매도

TVM:{"exchange":"upbit","account":"기본계정","symbol":"BTC/KRW","type":"limit","side":"sell","bal_pct":50,"price":"avg","price_pct":3,"token":"인증키"}:MVT

예시는 형식을 보여 드리기 위한 것입니다. 실제 메시지는 반드시 확장프로그램의 메시지 작성화면에서 만들어 주세요. 각 항목의 뜻은 주문메시지 항목 설명에 있습니다.

주의사항

  • 업비트 API키의 유효기간은 1년이며 연장할 수 없습니다. 만료 전에 새로 발급해 다시 등록해 주세요.
  • API키는 PC 웹에서만 발급할 수 있고, 2채널 인증이 필요합니다.
  • 현물 거래소이므로 레버리지·목표가·손절가·청산 같은 선물 옵션은 쓸 수 없습니다. 보유 코인은 매도로 정리합니다.
  • 주문수량(%)은 수수료를 고려해 최대 99% 까지 넣어 주세요.

자주 묻는 질문

Q. 업비트 자동매매도 컴퓨터를 켜 두어야 하나요?
아니요. 웹훅 방식은 트레이딩뷰 서버와 TVExtBot 클라우드 서버에서 처리되므로 컴퓨터를 꺼도 됩니다.

Q. 매수할 때마다 같은 금액으로 사고 싶어요.
amount_type 을 원화(krw)로 하거나, 주문수량(%)의 기준을 총자산 대비로 하면 매번 같은 금액으로 분할매수할 수 있습니다.
