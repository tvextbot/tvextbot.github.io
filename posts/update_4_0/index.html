TVExtBot 4.0 업데이트 안내

TVExtBot 확장프로그램 4.0.0은 화면 전체를 새로 정리한 버전입니다. 기능은 그대로 쓰면서, 처음 쓰는 분도 순서대로 따라 할 수 있게 바뀌었습니다.

한눈에 보는 변경점

  • 「시작하기」 체크리스트가 생겼습니다. 인증키 → API키 → 주문메시지 → 트레이딩뷰 얼러트 순서로 안내하고, 끝낸 단계는 자동으로 체크됩니다.
  • 「메시지 작성」 화면이 ①~⑥ 단계 카드로 바뀌고, 오른쪽 미리보기에서 주문 내용과 빠진 항목을 바로 확인할 수 있습니다.
  • 퀵주문 입력이 「메시지 작성」 화면에 합쳐졌습니다. 오른쪽 아래 「지금 바로 주문」 카드에서 퀵주문에 저장하거나 바로 주문합니다. 「퀵주문」 메뉴는 저장한 퀵주문을 실행하는 곳입니다.
  • 「전략 변환」(3.8.0부터): 트레이딩뷰 전략 코드를 붙여넣고 역할별로 주문메시지를 고르면 자동매매용 코드로 바꿔 줍니다.
  • 에러 메시지에 해결 방법이 함께 표시됩니다.

새 메시지 작성 화면 - 왼쪽 ①~⑥ 카드, 오른쪽 미리보기와 「지금 바로 주문」(퀵주문에 저장·바로 주문) 카드

달라진 버튼·위치

메뉴 이름은 그대로이고, 버튼 이름과 위치가 바뀌었습니다.

이전4.0
메시지 작성의 [메시지작성][메시지 만들기]
[메시지등록][+ 리스트에 저장]
[수정][변경 저장]
[복사] → 주문 메시지 / 단축 주문 메시지[전체 메시지] · [단축 메시지]
퀵주문 화면의 입력란메시지 작성의 「지금 바로 주문」 카드 → [퀵주문에 저장]
API키 표의 [연결중] / [중지] 버튼주문 허용 스위치 (켜짐 = 연결중, 꺼짐 = 차단)
메뉴 순서맨 위에 시작하기 추가, 주문내역·에러 메시지가 API키 등록 위로

새 메뉴 구성과 화면별 역할은 확장프로그램 화면 안내에서 한눈에 볼 수 있습니다.

자세한 사용법

  • 처음 시작한다면 → 코인·주식 자동매매 시작하기
  • 트레이딩뷰 전략을 연결한다면 → 전략 변환
  • 주문메시지를 만들 때 → 주문메시지 작성

업데이트 후 확인할 것

등록한 인증키·API키·주문메시지·퀵주문과 웹훅 URL은 그대로입니다. 트레이딩뷰 얼러트를 다시 만들 필요는 없습니다.

설정을 다 마치지 않았다면(인증키·API키·주문메시지 중 하나라도 없으면) 업데이트 후 첫 화면이 시작하기로 열립니다. 「시작하기 숨기기」를 누르면 메뉴에서 사라지고, 기본정보의 「시작하기 체크리스트」로 다시 볼 수 있습니다.

  • 확장프로그램 버전이 4.0.0인지 확인합니다. 아직 이전 버전이면 수동 업데이트 방법으로 바로 올릴 수 있습니다.
  • 트레이딩뷰 페이지를 열어 두었다면 새로고침해 주세요.
  • API키 등록 화면에서 거래소별 주문 허용 스위치가 켜져 있는지 확인해 주세요.
  • 메시지 작성 화면의 주문메시지 리스트가 그대로 있는지 확인해 주세요.
  • 트레이딩뷰 얼러트가 평소처럼 주문을 보내는지, 주문내역과 에러 메시지 화면에서 확인해 주세요.
  • 퀵주문을 고칠 때는 연필 버튼으로 메시지 작성에 불러와 고친 뒤 [퀵주문에 저장]을 누릅니다. 새 항목으로 추가되므로 이전 항목은 지워 주세요.

업데이트 후 이상이 있으면 주문이 안 될 때 확인할 것을 참고하시거나 메일()로 문의해 주세요.
