확장프로그램 화면 안내

왼쪽 메뉴의 화면이 각각 무엇을 하는 곳인지 한눈에 보는 안내입니다. 자세한 사용법은 화면별 링크를 따라가세요.

영상으로 보기 (5분) — 설치부터 전략 자동매매까지

테스트 모드 — 주문메시지나 전략에 켜 두면 얼러트가 와도 주문 직전까지만 확인하고 실제 주문은 보내지 않습니다. 새 얼러트·전략이 제대로 연결됐는지 주문 없이 확인할 수 있습니다. → 아래 안내

시작하기

① 설정 진행(4/4) ② 완료 안내와 [주문내역 보기] ③ 시작하기 숨기기 — 화면은 모든 단계를 끝낸 상태입니다

인증키 등록 → 거래소 API키 등록 → 주문메시지 만들기 → 트레이딩뷰 얼러트 연결 순서로 할 일을 보여 줍니다. 끝낸 단계는 자동으로 체크되고, 텔레그램 알림 연결은 선택입니다. 모두 끝나면 「설정을 모두 마쳤습니다」 안내가 나오고, [주문내역 보기]로 바로 결과를 확인할 수 있습니다. 설정을 다 마치기 전에는 확장프로그램을 열면 이 화면이 먼저 나옵니다. 「시작하기 숨기기」를 누르면 메뉴에서도 사라지고, 기본정보의 「시작하기 체크리스트」로 다시 볼 수 있습니다.

메시지 작성

왼쪽 ①~⑥ 카드와 오른쪽 미리보기·「지금 바로 주문」 카드

왼쪽 카드 ①~⑥을 위에서부터 채우면 오른쪽 미리보기에 주문 내용과 빠진 항목이 바로 표시됩니다.

  • ① 어디서 거래할까요: 거래소·계정·종목·거래마켓
  • ② 어떻게 주문할까요: 주문방법(매수·매도·청산)·주문유형·주문가격
  • ③ 얼마나 주문할까요: 개수·금액 또는 자산 대비 % 중 하나
  • ④ 포지션·리스크 관리(선물): 레버리지·목표가·손절가·추적손절매 등
  • ⑤ 실행 조건: 지연시간·거래시간 등
  • ⑥ 메모: 리스트에서 알아보기 쉽게 주문 내용을 적기

「메시지 만들기」 → 「리스트에 저장」한 뒤 「전체 메시지」나 「단축 메시지」를 복사해 얼러트에 넣습니다. 오른쪽 아래 「지금 바로 주문」 카드는 퀵주문을 만드는 곳입니다.

저장한 메시지는 화면 아래 주문메시지 리스트에 쌓입니다. 행을 클릭하면 위 입력란으로 불러오고, 오른쪽 클릭으로 복사·삭제·활성화/비활성화·테스트 모드, 끌어서 순서 변경을 할 수 있습니다.

테스트 모드 NEW

주문메시지 리스트의 행을 오른쪽 클릭해 「테스트 모드 켜기」를 누르거나, 메시지를 불러온 뒤 미리보기 아래 「테스트」의 버튼을 누르면, 그 주문메시지(주문ID)로 온 얼러트는 인증키·주문메시지·API키 연결까지 확인하고 거래소에 주문을 보내지 않습니다. 결과는 텔레그램의 「🧪 테스트 수신 (주문 안 함)」 알림과 전략 변환 목록의 「얼러트 수신」에서 확인합니다.

① 주문메시지 행을 오른쪽 클릭 ② 「테스트 모드 켜기」

미리보기 아래 「테스트」 버튼 — 리스트에서 메시지를 불러오면 누를 수 있습니다

켜진 주문메시지는 「옵션」 칸 맨 앞에 「테스트 모드」 표시가 붙습니다. 확인이 끝나면 같은 메뉴의 「테스트 모드 끄기」로 끄세요.

  • 주문ID로 온 얼러트(단축 주문메시지·전략 변환)에만 적용됩니다. 「전체 메시지 복사」로 붙여넣은 얼러트는 주문합니다.
  • 수량·잔고·포지션은 확인하지 않습니다. 실제 주문 처리까지 보려면 테스트넷을 쓰세요.
  • 자세한 순서와 유의사항은 테스트 모드로 확인하기를 보세요.

퀵주문

① 새 퀵주문 만들기 ② 실행 ③ 수정(연필)

얼러트 없이 버튼 하나로 거래소에 바로 주문합니다. 퀵주문은 이 화면이 아니라 메시지 작성에서 만듭니다.

  • 만들기: 메시지 작성에서 주문 내용을 입력하고 「지금 바로 주문」 카드의 퀵주문에 저장(최대 100개). 이 화면의 「새 퀵주문 만들기」를 눌러도 메시지 작성으로 넘어갑니다. 저장하지 않고 한 번만 주문하려면 바로 주문.
  • 실행: 리스트의 「실행」 → 확인창에서 한 번 더 확인 후 주문(기본설정에서 확인창 생략 가능). 체크한 여러 개는 「선택한 주문 실행」으로 한 번에 실행하고, 방향·거래소·검색으로 리스트를 거를 수 있습니다.
  • 고치기: 연필 버튼으로 메시지 작성에 불러와 고친 뒤 「퀵주문에 저장」. 새 항목으로 추가되므로 이전 항목은 삭제하세요.

지연시간·거래시간·조건식은 얼러트 전용입니다. 바로 주문하거나 퀵주문에 저장하려면 해당 설정을 꺼야 하고, 켜 둔 채 누르면 경고가 뜨고 실행·저장되지 않습니다.

전략 변환

트레이딩뷰 전략(Pine Script v5·v6) 코드를 붙여넣으면 매매 로직은 그대로 두고 주문메시지 연결과 백테스트 기간 설정만 추가합니다. 코드 확인 → 주문메시지 연결 → 트레이딩뷰 설정 3단계로 진행하고, 변환한 전략은 목록으로 관리합니다. 목록에서는 전략마다 마지막 얼러트 결과(「얼러트 수신」)를 보고, 「테스트 모드」 버튼 NEW으로 연결한 주문메시지를 한꺼번에 테스트 모드로 바꿀 수 있습니다. 자세한 내용은 전략 변환을 보세요.

① [테스트 모드] — 연결한 주문메시지를 한꺼번에 켜고 끕니다 ② 역할마다 마지막 얼러트 결과(「주문됨」·「테스트 수신 성공」 등)

주문내역

① 전체·웹훅·퀵주문 구분 ② 조회 기간

웹훅과 퀵주문으로 실행한 주문을 날짜별로 최근 순으로 보여 줍니다. 위의 「전체·웹훅·퀵주문」으로 거르고, 「조회 기간」에서 지난 달을 고를 수 있습니다. 체결을 기다리는 주문은 위에 「체결 대기 n건」으로 표시되고 행의 취소 버튼으로 취소할 수 있습니다. 리스트 끝까지 스크롤하면 이전 주문을 이어서 불러옵니다.

에러 메시지

① 해결 방법 ② 에러 내용 복사

서버에서 주문이 실패하면 이유·해결 방법·주문 원문이 여기에 남습니다(7일 보관). 해결 방법대로 고쳐도 안 되면 에러 내용을 복사해 문의해 주세요. 자주 나오는 에러는 주문이 안 될 때를 보세요.

API키 등록

① 등록된 계정·주문 허용·주문 차단 수 ② 주문 허용 스위치 ③ 계정 추가 IP주소와 키 값은 가렸습니다

거래소에서 발급받은 API키를 등록합니다. 위쪽 카드에서 등록된 계정·주문 허용·주문 차단 수를 한눈에 볼 수 있고, 「계정 추가」로 한 거래소에 계정을 여러 개 등록할 수 있습니다. 주문 허용을 끄면 키는 남겨 두고 그 계정의 주문만 막습니다. 잠시 멈출 때는 삭제 대신 끄세요. 발급 방법은 API키 등록을 보세요.

인증키 등록

① 인증키 입력 ② 인증완료 ③ 결제(기간연장)

이메일과 인증키를 넣고 「인증하기」를 누르면 웹훅 자동매매와 텔레그램 알림 등 모든 기능을 쓸 수 있습니다. 인증이 끝나면 버튼이 「인증완료」로 바뀌고 오른쪽 위에 버전과 유효기간이 표시됩니다. 유효기간 안에 「결제(기간연장)」로 결제하면 인증키를 바꾸지 않고 기간이 늘어납니다. 인증키가 없으면 무료 인증키를 발행해 테스트넷에서 1개월 동안 무료로 써 볼 수 있고, 아래 「인증키 구매」에서 USDT로 결제할 수 있습니다. 자세한 내용은 인증키 발급을 보세요.

기본설정

① 텔레그램 개인 알림 ② 텔레그램 채널 알림 ③ 이메일 알림 ④ 퀵주문

알림과 퀵주문 동작을 설정하며, 바꾸면 바로 저장됩니다.

  • 텔레그램 개인 알림: 「연결」을 누르고 텔레그램에서 「시작」. 매일 저녁 8시 일일 리포트, 컨트롤 센터 포지션 청산 허용
  • 텔레그램 채널 알림·이메일 알림: 매매와 에러 정보를 채널·메일로 받기(텔레그램 채널 알림)
  • 퀵주문: 결과 음성 안내, 확인창 없이 바로 주문(실수로 누르지 않게 주의)

기본정보

① 처음이라면(바로가기) ② 사용 전 확인하세요
