텔레그램 컨트롤 센터 사용법 (보유자산 조회·API 연결/차단)

TVExtBot 컨트롤 센터는 텔레그램에서 거래소 계정의 보유자산을 조회하고, API를 연결/차단할 수 있는 봇입니다.
외출 중에도 스마트폰으로 잔고를 확인하고, 급할 때는 모든 계정의 자동매매를 한 번에 멈출 수 있습니다.

컨트롤 센터로 할 수 있는 것

명령어기능
💰 /balance거래소별 보유자산 조회
🔌 /status_api계정별 API 연결상태 확인
🔧 /control_api계정별 API 연결/차단
🚨 /control_all모든 계정 API 한 번에 연결/차단
▶️ /start사용자 등록 (처음 한 번)
❓ /help사용법

주문 결과와 에러 알림은 컨트롤 센터가 아니라 개인 알림봇(@TTVExtBot)으로 받습니다. 두 봇은 역할이 다르니 둘 다 등록해 두세요.

시작하기

1.먼저 TVExtBot 설정화면의 기본설정에 텔레그램 사용자명이 등록되어 있어야 합니다. 아직이라면 텔레그램 개인 알림봇 사용법의 2~3번을 따라 등록해 주세요.

2.아래 QR코드를 스마트폰으로 찍거나, 링크를 눌러 컨트롤 센터를 엽니다. 확장프로그램 설정화면의 텔레그램 부가서비스에 있는 [컨트롤 센터] 링크로도 열 수 있습니다.
https://t.me/iTVExtBot

3.봇 화면 아래의 [시작] 을 누릅니다. 「TVExtBot 컨트롤 센터를 시작합니다.」 메시지가 오면 등록이 끝난 것입니다.

「사용자정보가 없습니다」 라는 메시지가 오면 확장프로그램 기본설정의 텔레그램 사용자명이 등록되지 않았거나 다른 경우입니다. 사용자명을 다시 입력해 적용한 뒤 /start 를 다시 보내 주세요.

4.입력창 왼쪽의 [메뉴] 를 누르거나 / 를 입력하면 명령어 목록이 나옵니다.

하나의 텔레그램에 인증키가 여러 개 연결되어 있으면, 명령어를 보낼 때 먼저 인증키 등록에 사용한 메일을 고르는 버튼이 나옵니다.

보유자산 조회 (/balance)

/balance 를 보내고 거래소를 고르면, 그 거래소에 등록한 모든 계정의 보유자산을 보여 줍니다.

  • 지원 거래소: 빗썸, 업비트, 바이빗, 바이낸스, 비트겟, Phemex, OKX, BingX, 한국투자증권, 키움증권
  • 바이낸스·바이빗·비트겟·Phemex는 현물과 선물을 한 번에 조회하고, 자산이 있는 쪽만 표시합니다.
  • 주식은 국내·해외 예수금, 평가금액, 평가손익과 종목별 보유수량(평가손익률)을 보여 줍니다. 해외 금액은 한국투자증권은 원화 환산, 키움증권은 USD 로 표시됩니다.
  • 조회에 몇 초 걸릴 수 있습니다.

API 연결상태 확인 (/status_api)

거래소를 고르면 등록된 계정마다 연결중 / 차단중 상태를 보여 줍니다. 확장프로그램의 API키 등록 화면에 있는 [연결중]·[차단중] 과 같은 상태입니다.

계정별 API 연결/차단 (/control_api)

거래소를 고르면 계정마다 [계정명] 연결, [계정명] 차단 버튼이 나옵니다. 원하는 버튼을 누르면 바로 바뀝니다.

  • 차단중인 계정은 얼러트가 와도 주문하지 않습니다. 특정 전략이나 계정만 잠시 멈추고 싶을 때 사용하세요.
  • 다시 자동매매를 하려면 같은 화면에서 연결을 누릅니다.

모든 계정 한 번에 연결/차단 (/control_all)

급락장이나 전략 오류처럼 자동매매를 당장 전부 멈춰야 할 때 사용합니다.

  1. /control_all 을 보내고 [🚨 전부 차단] 또는 [✅ 전부 연결] 을 고릅니다.
  2. 바뀔 계정 목록이 나오면 확인한 뒤 [전체 차단](또는 [전체 연결])을 누릅니다. 취소하려면 [취소] 를 누릅니다.
  3. 계정별 결과가 표시됩니다. 실패한 계정이 있으면 /control_api 로 다시 시도해 주세요.

전부 연결은 일부러 차단해 둔 계정까지 모두 연결하고, 연결되는 순간부터 자동매매 주문이 실행됩니다. 목록을 꼭 확인해 주세요.
테스트넷·모의투자 계정은 전체 연결/차단 대상에서 빠집니다.

자주 묻는 질문

Q. 컨트롤 센터에서 차단하면 이미 들어간 주문이나 포지션도 정리되나요?
아니요. 차단은 이후에 오는 얼러트의 주문을 막는 것입니다. 이미 체결된 포지션이나 거래소에 걸려 있는 미체결 주문은 거래소에서 직접 정리해 주세요.

Q. 알림봇(@TTVExtBot)과 무엇이 다른가요?
알림봇은 주문 결과와 에러를 받는 봇이고, 컨트롤 센터는 잔고 조회와 API 연결/차단을 하는 봇입니다.

Q. 텔레그램 사용자명을 바꿨어요.
확장프로그램 기본설정에 새 사용자명을 다시 입력해 적용한 뒤, 컨트롤 센터에서 /start 를 다시 보내 주세요.


주문 결과와 에러도 실시간으로 받으려면 → 텔레그램 개인 알림봇 사용법
