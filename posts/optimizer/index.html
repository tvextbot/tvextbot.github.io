TVExtBot 옵티마이저 사용법: 트레이딩뷰 전략 설정값 자동 백테스트

전략의 숫자 설정값을 여러 조합으로 백테스트하고, 결과를 비교하는 Chrome 확장 프로그램입니다.

처음에는 적은 조합으로 실행해 보세요. 설정 → 실행 → 보고서 확인 → 선택한 값 적용 순서로 사용합니다.

1. 설치하기

  1. Chrome 웹 스토어에서 TVExtBot 옵티마이저를 설치합니다.

TVExtBot 옵티마이저 설치하기

  1. Chrome의 확장 프로그램 메뉴에서 옵티마이저를 고정(핀)하면 편리합니다.

2. TradingView 준비하기

  1. 차트에 최적화할 전략을 추가합니다.
  2. 종목·시간봉·백테스트 기간을 정합니다.
  3. 전략 테스터의 오버뷰(Overview)를 엽니다.
  4. 전략 설정의 인풋(Inputs) 탭을 열어 둡니다.
  5. Chrome에서 옵티마이저 아이콘을 누릅니다.

지표(indicator)는 백테스트 대상이 아닙니다. 전략(strategy)을 사용해 주세요.

실행 중에는 차트·전략·인풋·프로퍼티를 변경하지 마세요. 페이지 새로고침도 실행을 중단시킬 수 있습니다.

3. 테스트할 값 입력하기

  1. 항목번호 확인을 누릅니다.
  2. TradingView 숫자 입력창에 표시된 번호를 확인합니다.
  3. 해당 번호와 시작값·종료값·스텝값을 입력합니다.
  4. 여러 값을 함께 비교하려면 항목 추가를 누릅니다.
입력칸의미예시
항목번호변경할 숫자 인풋의 번호7
시작값처음 테스트할 값10
종료값테스트 범위의 상한14
스텝값값을 늘리는 간격2

이 예시는 10 → 12 → 14, 세 값을 테스트합니다.

두 항목의 값이 각각 3개와 4개라면 3 × 4 = 12조합입니다. 위 화면은 4개 값 × 4개 값으로 총 16조합입니다.

  • 시작값은 종료값보다 작아야 합니다.
  • 스텝값은 0보다 커야 합니다. 인풋이 허용하는 단위로 입력하세요.
  • 종료값이 스텝과 맞지 않으면 종료값을 넘지 않는 값까지만 실행합니다.
  • 같은 항목번호를 중복해서 넣을 수 없습니다.
  • 체크박스·선택 목록은 최적화할 수 없습니다.

무료·인증 사용자 모두 항목을 최대 8개까지 추가할 수 있습니다.

  • 8개가 되면 버튼에 최대 8개까지 추가할 수 있습니다가 표시되며 비활성화됩니다.
  • 필요 없는 행은 해당 행 오른쪽의 ✕로 삭제합니다. 삭제하면 다시 추가할 수 있습니다.
  • 이전 버전에서 8개 넘게 저장했다면, 실행 전에 8개 이하로 줄여 주세요. 기존 항목은 자동 삭제하지 않습니다.

항목 수 제한과 백테스트 실행 횟수 제한은 별개입니다. 항목이 8개 이하여도 실행 한도에 도달하면 중지됩니다.

번호 표시를 끄려면 항목번호 확인을 다시 누릅니다. 인풋창을 닫아도 번호는 사라집니다.

4. 실행 설정 조정하기

실행 설정을 펼치면 대기 시간과 연속 실행 시간을 조정할 수 있습니다.

설정용도입력 범위
백테스트 대기(초)결과 갱신을 기다리는 기준 시간5~300초
회차 간격(초)다음 백테스트 전 추가로 쉬는 시간0~60초, 비우면 1초
연속 실행 시간새 백테스트 제출을 멈추는 시점무료 1시간 고정 / 인증 1·2·4시간·제한 없음

인증 이용은 기본 2시간입니다. 인증이 만료돼 무료로 바뀌어도 고른 시간은 남아 있으며, 다시 인증하면 그대로 적용됩니다. 무료 이용에서는 1시간으로 고정되어 변경할 수 없습니다.

4시간이나 「제한 없음」을 선택하면 위험 확인 창이 뜹니다. 동의해야 저장되며, 취소하면 이전 선택으로 돌아갑니다. 시간 제한은 계정 보호를 위한 안전장치이며, 계정 제한 방지를 보장하지는 않습니다.

회차 간격은 TradingView에 보내는 요청 빈도를 낮추기 위한 값입니다. 조합이 많을수록 줄이기보다 기본값 이상으로 두기를 권합니다.

무거운 전략은 백테스트 대기를 늘려 주세요. 실제 계산 시간을 측정하면 대기 한도를 자동으로 늘립니다. 최대 300초입니다.

대기 시간은 매번 모두 소비하는 고정 시간이 아닙니다. 결과 갱신을 확인하면 다음 단계로 진행합니다.

5. 실행하고 중지하기

최적화를 누르면 인풋 변경과 확인(OK) 제출이 자동으로 반복됩니다. 실행이 시작되면 같은 버튼이 중지로 바뀝니다.

실행 횟수가 500회를 넘으면 「총 N회 백테스트를 실행합니다」 안내가 뜨고, 10초 안에 같은 버튼을 한 번 더 눌러야 시작합니다. 스마트 최적화는 일부 조합만 실행하므로 최대 약 N회로 안내합니다.

실행 중에는 팝업 위쪽(소개 카드 바로 아래)에 진행 상황이 표시됩니다.

  • 저장한 조합 수 / 전체 조합 수
  • 진행률·경과 시간·예상 남은 시간
  • 갱신 확인·미확인 개수
  • 실제 제출 횟수·새 제출 마감까지 남은 시간

무료는 「제출 124 / 500회」, 인증은 「제출 124회」처럼 표시됩니다. 시간 제한이 있으면 실행 중에만 「마감까지」가 함께 나옵니다. 완료·중지 후에는 제출 횟수만 남습니다.

실행 중 팝업 아래 요약은 입력값 대신 실행 중인 작업을 기준으로 표시됩니다. 이어하기·재검증·스마트 최적화의 조합 수와 실제 적용된 백테스트 대기·회차 간격·연속 실행 시간·이용 권한을 확인할 수 있습니다.

처음에는 예상 시간을 계산하는 데 몇 회차가 필요합니다. 무거운 전략이나 긴 대기 시간이 있으면 예상 시간도 늘어납니다.

팝업을 닫아도 실행은 계속됩니다. 같은 TradingView 탭에서 다시 열면 진행 상태가 표시됩니다. 아이콘의 진행률 배지도 해당 탭에서 보입니다.

멈추려면 중지를 누르고 처리가 끝날 때까지 기다려 주세요. 완료한 결과는 부분 보고서로 저장됩니다.

종료 화면의 보고서 열기로 결과를 확인합니다. ×는 진행 표시만 닫으며, 보고서를 삭제하지 않습니다.

스마트 최적화(인증 이용)

최적화 버튼 오른쪽 ▾ → 스마트 최적화를 선택합니다. 선택은 저장되지 않으므로 실행할 때마다 메뉴에서 골라 주세요. 메뉴에는 1단계 예상 실행 횟수(약 N회~)가 함께 표시됩니다.

최적화는 모든 조합, 스마트 최적화는 일부만 실행합니다. 먼저 범위 전체를 듬성듬성 확인한 뒤, 순익이 좋은 조합 주변에서 항목 하나씩 바꿔 봅니다. 갱신 확인된 결과만 주변 탐색의 기준으로 사용하며, 최고 조합을 보장하지 않습니다.

조건메뉴 표시
전체 200조합 이하스마트 최적화 비활성화. 최적화 버튼으로 전체 조합 실행
전체 10만 조합 초과스마트 최적화 비활성화
미인증🔒 인증 전용 표시와 함께 비활성화

실행을 시작할 때 인증을 확인하지 못하면 전체 조합으로 진행하며 무료 이용 한도가 적용됩니다.

진행 표시에는 스마트 최적화 1단계(전체 훑기) 또는 스마트 최적화 2단계(주변 탐색)가 나옵니다. 2단계에서는 남은 시간이 계산 중으로 표시됩니다.

보고서의 전체 조합으로 채우기로 남은 조합을 실행할 수 있습니다. 전체 조합을 채우면 갱신 확인된 결과 안에서 스마트 최적화 최고 조합의 순위를 표시하고, 미확인으로 제외한 개수도 안내합니다. 최고 조합 자체가 미확인이면 순위를 확인할 수 없습니다.

탐색 기준은 순익입니다. 보고서의 분석 필터는 스마트 최적화의 후보 선택에 반영되지 않습니다.

6. 무료 이용과 인증 이용

이용 인증 탭에 TVExtBot 이용자의 이메일과 인증키를 등록합니다. 유효한 인증이면 제출 횟수 제한 없이 이용할 수 있습니다. 연속 실행 시간은 기본 2시간입니다. 인증키 발급은 인증키 등록·구매 가이드를 참고하세요.

인증 후에는 등록한 이메일과 이용 기한만 표시됩니다. 팝업을 열 때마다 인증을 다시 확인하며, 인증키가 만료되거나 유효하지 않으면 자동으로 해제됩니다.

이용 상태작업당 제출 한도하루 제출 한도작업 시간
미인증·인증 만료500회500회1시간 고정
유효한 인증키 등록제한 없음제한 없음기본 2시간(변경 가능)

일반 최적화·재검증·이어하기에 같은 기준을 적용합니다. 연속 실행 시간은 원본 보고서가 아닌 현재 설정을 사용합니다. 실행 중 설정을 바꿔도 진행 중인 작업에는 반영되지 않습니다.

최적화는 브라우저 전체에서 한 번에 하나만 실행됩니다. 다른 TradingView 탭에서 실행 중이면 그 작업이 끝나거나 중지한 뒤 시작해 주세요.

인증 이용 여부는 작업을 시작할 때마다 인증 서버에서 확인합니다. 인증키가 확인되지 않거나 인증 서버에 연결하지 못하면 그 작업에는 무료 한도가 적용되고, 진행 표시에 그 이유가 나타납니다.

한도는 저장 조합 수가 아닌 실제 제출 기준입니다. 초기화나 중복 계산이 포함되어 저장된 조합 수보다 먼저 한도에 도달할 수 있습니다.

한도에 도달하면 결과와 중지 사유를 저장합니다. 남은 조합은 이어하기로 진행할 수 있지만, 무료 일일 한도는 그대로 적용됩니다.

무료 일일 횟수는 기기의 현지 날짜 기준 자정에 초기화됩니다. 작업 시간은 첫 제출을 위한 인증 확인이 끝난 뒤부터 계산하며, 진행 중인 계산을 마친 뒤 다음 제출 전에 중지합니다.

이 한도는 TradingView의 허용량이나 계정 제한 방지를 보장하는 기준은 아닙니다.

7. 저장된 보고서 열기

팝업의 보고서 탭에서 열기를 누르면 상세 보고서가 새 탭으로 열립니다.

  • 검색: 전략명 등으로 보고서를 찾습니다.
  • 새로고침: 최신 저장 결과를 불러옵니다.
  • 열 선택 메뉴: 날짜·종목·최대 순익 등 표시할 정보를 고릅니다.
  • 휴지통: 한 번 누르면 빨간 삭제 확인 버튼으로 바뀌고, 3초 안에 한 번 더 누르면 삭제합니다. 삭제한 보고서는 복구할 수 없습니다.

보고서는 브라우저에 저장됩니다. 확장 프로그램을 삭제하면 보고서·설정·인증 정보도 지워집니다. 필요한 결과는 미리 CSV로 보관하세요.

8. 결과 요약과 필터 보기

상단 카드에서 최고 순익금·가장 낮은 최대손실률·수익 조합 비율·필터 통과 조합 수를 확인합니다.

각 카드는 전체 결과를 요약합니다. 서로 다른 조합에서 나온 수치일 수 있습니다.

최소 거래 수

거래 횟수가 설정값 이상인 조합만 분석합니다.

설정값표시 대상
0거래 수 제한 없음
30총 거래 30회 이상

거래가 몇 번 없는데 수익만 높게 나온 조합을 걸러낼 때 사용합니다. 저장된 결과를 삭제하지는 않습니다.

최대손실률 상한

최대손실률이 설정값 이하인 조합만 분석합니다. 비우거나 0이면 제한하지 않습니다.

설정값표시 대상
(비움)손실률 제한 없음
20최대손실률 20% 이하

감당할 수 있는 손실 한도를 먼저 정하고, 그 안에서 순익이 가장 높은 조합을 찾을 때 사용합니다. 최소 거래 수와 함께 적용되며, 요약 카드·히트맵·표·CSV 모두 같은 조건을 따릅니다. 최대손실률 값이 없는 조합은 제외됩니다.

갱신 확인·미확인은 무엇인가요?

표시의미확인 방법
갱신 확인제출 후 결과 지표가 바뀐 것을 감지함중요한 조합은 수동 결과와 대조
갱신 미확인대기 중 변화를 감지하지 못해 당시 화면 값을 저장함재검증 또는 직접 적용 후 확인
기존 보고서확인 상태를 기록하지 않은 예전 보고서필요한 조합을 직접 확인

미확인이 반드시 틀린 결과는 아닙니다. 설정값이 달라도 거래 결과가 같으면 숫자가 바뀌지 않습니다. 계산이 늦어 이전 결과가 남았을 가능성도 있습니다.

미확인 결과는 기본적으로 분석에서 제외합니다. 보려면 갱신 미확인 포함을 선택하세요.

갱신 확인도 정확성을 보증하지는 않습니다. 실시간 시세에 따른 숫자 변경이 감지될 수 있습니다.

9. 파라미터 히트맵 사용하기

히트맵은 두 항목의 값에 따라 결과가 어떻게 달라지는지 색으로 보여 줍니다.

  1. 가로축과 세로축에 비교할 항목을 선택합니다.
  2. 표시 지표에서 순익금 또는 최대손실률을 고릅니다.
  3. 항목이 3개 이상이면 나머지 항목의 값을 고정합니다.
  4. 셀을 누르면 전체 파라미터와 결과를 확인할 수 있습니다.

전체 결과보다 칸 수가 적은 이유

예를 들어 163조합을 저장했더라도, 선택한 두 축의 값이 각각 3개라면 현재 구간은 3 × 3 = 9칸일 수 있습니다.

나머지 항목은 선택한 값으로 고정되어 있기 때문입니다. 고정값을 바꾸면 다른 구간을 볼 수 있습니다.

전체 결과는 아래 상세 표에서 확인합니다. 히트맵의 고정값을 바꿔도 기본 상세 표와 상단 요약은 줄어들지 않습니다.

색상과 표시 읽기

표시의미
파랑 / 주황순익금 기준 수익 / 손실
최대손실률의 주황 농도손실률 크기 비교. 낮은 값이 유리
★현재 구간의 최고 순익 또는 가장 낮은 손실률
제외분석 필터로 숨긴 조합
없음저장된 결과가 없는 조합

0도 유효한 결과입니다. ★는 현재 구간의 최적값이며, 안정성이나 미래 성과를 보장하지 않습니다.

색상 기준은 전체 필터 통과 결과에 맞춥니다. 축·고정값을 바꿔도 같은 색은 같은 수치를 뜻합니다.

10. 상세 표와 CSV 사용하기

상세 표는 기본적으로 전체 저장 결과에 분석 필터를 적용한 목록입니다.

  • 열 제목을 누르면 해당 지표로 정렬합니다.
  • 검색창으로 표 안의 결과를 찾습니다.
  • 페이지당 표시 개수와 페이지를 바꿔 전체 목록을 확인합니다.
  • 행을 누르면 해당 조합이 선택됩니다.
  • 순익금·순익률은 파랑이 수익, 주황이 손실입니다. 히트맵 색과 같습니다.
  • 맨 끝 결과 확인 열은 갱신 확인을 확인, 갱신 미확인을 노란 미확인으로 표시합니다.

히트맵에서 선택한 구간만 보기를 체크하면 표와 CSV도 해당 구간으로 좁혀집니다. 상단 요약은 그대로입니다.

조작적용 범위
최소 거래 수·최대손실률 상한·미확인 포함요약·히트맵·표·CSV
히트맵의 축·고정값 변경히트맵
선택한 구간만 보기표·CSV
표 검색·페이지 이동표만

상단의 CSV 내보내기로 결과를 저장합니다. 검색어와 현재 페이지에 관계없이, 분석 필터와 구간 조건에 맞는 전체 결과를 내보냅니다.

11. 선택한 조합을 TradingView에 적용하기

  1. 히트맵 셀이나 표 행을 선택합니다.
  2. TradingView에 적용을 누릅니다.
  3. 대상 TradingView 탭을 선택하고 적용을 누릅니다.
  4. 인풋창의 값을 확인한 뒤 확인(OK)은 직접 누릅니다.

선택한 최적화 항목만 변경합니다. 처음 사용하면 TradingView 접근 권한을 요청할 수 있습니다.

값 복사로 선택한 파라미터를 클립보드에 복사할 수도 있습니다.

전략이나 입력 구성이 다르면 적용을 차단합니다. 입력 구성 정보가 없는 옛 보고서에서는 직접 적용을 사용할 수 없습니다.

12. 재검증과 이어하기

기능언제 사용하나요?실행 대상
미확인 재검증 (N)결과 갱신을 확인하지 못했을 때원본 보고서 전체의 미확인 조합
이어하기 (N)중단한 작업을 마저 실행할 때원래 계획에서 아직 저장하지 않은 조합
  1. 원본과 같은 전략·종목·시간봉·기간·설정을 준비합니다.
  2. 보고서에서 원하는 기능을 누릅니다.
  3. 대상 탭과 안내를 확인하고 시작을 누릅니다.

두 기능은 인풋 변경과 OK 제출을 자동으로 수행합니다. 진행 확인과 중지는 대상 TradingView 탭의 팝업에서 합니다.

결과는 원본 보고서에 합쳐집니다. 없던 조합은 추가하고, 이미 있는 조합은 갱신 확인된 새 결과로 교체합니다. 교체한 결과는 되돌릴 수 없습니다. 새 결과가 다시 미확인인 경우 등 그 밖에는 기존 값을 유지합니다.

원본 보고서가 삭제됐으면 새 보고서로 저장하고 안내합니다. 이어하기는 실행 시 가져온 기존 결과도 함께 보존합니다.

열린 보고서에는 결과가 갱신됐습니다 [새로고침] 안내가 뜹니다. 새로고침해 반영된 결과를 확인해 주세요. 보고서 머리에는 최근 실행(이어하기·재검증) 시각과 추가·교체한 조합 수가 표시됩니다.

알아둘 점:

  • 재검증은 현재 필터나 선택 행과 관계없이 전체 미확인 조합을 실행합니다.
  • 미확인도 저장된 조합이므로 이어하기에서는 건너뜁니다.
  • 이어하기는 원래 대기 시간·회차 간격을 사용합니다.
  • 연속 실행 시간은 이어하기·재검증을 시작할 때의 현재 설정을 사용합니다.
  • 진행률은 이번에 실행할 남은 조합 기준입니다.
  • 완료 보고서나 실행 계획이 없는 옛 보고서는 이어할 수 없습니다.
  • 전체 계획이 10만 조합을 넘으면 이어하기를 지원하지 않습니다.

실행 조건이 다르면 변경된 항목을 안내하고 차단합니다. 조건을 자동 복원하지 않으므로 원래 차트 설정을 직접 맞춰 주세요.

13. 자주 묻는 질문

시작되지 않아요

전략 테스터의 오버뷰와 해당 전략의 인풋 탭을 열어 주세요. 항목번호·중복 번호·범위·스텝값도 확인합니다.

스마트 최적화를 선택할 수 없어요

전체 조합이 200개 이하이거나 10만 개를 초과하면 스마트 최적화 메뉴가 비활성화됩니다. 미인증이면 🔒 인증 전용으로 표시되므로 이용 인증 상태를 확인해 주세요. 실행 중에는 ▾ 메뉴가 숨겨집니다. 작업이 끝나거나 중지한 뒤 다시 선택해 주세요.

「이미 실행 중」 또는 「다른 탭에서 실행 중」 알림이 떠요

최적화는 브라우저 전체에서 한 번에 하나만 실행됩니다. 실행 중인 탭의 팝업에서 진행 상황을 확인하고, 끝나거나 중지한 뒤 다시 시작해 주세요. 실행하던 탭이 비정상 종료되었거나 메모리 절약으로 페이지가 해제된 경우에는 다음 실행 때 자동으로 확인해 잠금을 풉니다.

인증했는데 500회에서 멈추거나 「무료 한도」 안내가 떠요

작업을 시작할 때 인증 서버가 인증키를 확인하지 못하면 그 작업은 무료 한도로 진행되며, 진행 표시에 이유가 나옵니다. 「연결하지 못해」라면 네트워크를 확인한 뒤 다시 실행하고, 「인증키가 확인되지 않아」라면 이용 인증 탭에서 인증 상태와 이용 기한을 확인해 주세요. 남은 조합은 이어하기로 진행할 수 있습니다.

인증했는데 2시간 뒤에 멈춰요

계정 보호를 위한 연속 실행 시간이 지나 새 제출을 멈춘 것입니다. 결과는 저장되며, 남은 조합은 이어하기로 진행할 수 있습니다. 시간은 실행 설정에서 바꿀 수 있습니다.

「결과를 저장하지 못했어요」 알림이 떠요

컴퓨터의 디스크 공간을 확인하고, 필요 없는 보고서를 삭제한 뒤 다시 실행해 주세요.

첫 조합에서 오래 기다려요

일반 최적화에서 아직 계산 시간을 측정하지 못했다면 최대 300초 기다릴 수 있습니다. 첫 조합의 결과가 이전과 같아도 발생할 수 있습니다.

무거운 전략도 사용할 수 있나요?

백테스트 대기를 충분히 설정하세요. 계산 시간이 측정되면 자동 조정합니다. 미확인 결과는 수동 확인이나 재검증을 권합니다.

히트맵이나 표에 결과가 적게 나와요

최소 거래 수·최대손실률 상한과 갱신 미확인 포함을 확인하세요. 표에서는 선택한 구간만 보기와 검색어도 확인합니다.

업데이트 후 오류가 나요

확장 프로그램을 다시 로드한 뒤 TradingView와 보고서 페이지도 새로고침합니다. 실행 중인 작업은 먼저 중지하고 저장을 확인해 주세요.

실행 중에 확장 프로그램이 업데이트되거나 다시 로드되면 작업이 바로 멈추고, 그 실행의 결과는 저장되지 않을 수 있습니다.

화면 색상을 바꾸고 싶어요

팝업 헤더의 작은 스위치로 다크·라이트 모드를 전환합니다. 선택은 저장되며 상세 보고서에도 적용됩니다.

좋은 조합은 어떻게 고르나요?

순익만 보지 말고 거래 수·최대손실률·주변 값의 결과를 함께 비교하세요. 고른 조합은 다른 기간에서도 직접 확인해 보세요.

TradingView 계정에 문제가 생길 수는 없나요?

TVExtBot 옵티마이저는 TradingView와 제휴하거나 승인받지 않은 독립 도구입니다. 사용자 본인의 TradingView 화면에서 인풋 변경과 확인(OK)을 대신 누를 뿐이지만, 자동화된 사용은 TradingView 이용약관에 따라 계정 제한 사유가 될 수 있습니다. 이용에 따른 책임은 사용자에게 있습니다.

위험을 줄이려면 회차 간격을 기본값(1초) 이상으로 두고, 한 번에 지나치게 많은 조합을 실행하지 마세요. 실행은 브라우저 전체에서 한 번에 하나만 진행됩니다.
