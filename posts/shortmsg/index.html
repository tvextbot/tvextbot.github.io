단축 주문메시지 사용법

단축 주문메시지란 기존의 긴 주문메시지를 짧게 줄인 주문메시지입니다.

기존 주문메시지는 내용을 고치면 트레이딩뷰 얼러트도 다시 설정해야 합니다. 단축 주문메시지는 내용이 주문ID와 함께 클라우드 서버에 저장되므로, 내용을 고쳐도 얼러트를 다시 설정할 필요가 없습니다.

유의사항
  • 주문ID는 프로그램이 자동으로 만들기 때문에 직접 바꿀 수 없습니다.
  • 리스트에서 주문메시지를 삭제하면 그 단축 주문메시지는 쓸 수 없습니다. 이후 얼러트가 오면 「등록되지 않은 주문ID」 텔레그램 알림이 옵니다.
  • 삭제한 뒤 같은 내용으로 새로 저장해도 주문ID가 달라지므로 얼러트를 다시 설정해야 합니다.
  • 잠시 주문을 멈추려면 삭제 대신 비활성화하세요. 얼러트가 와도 주문하지 않고 「비활성화된 주문메시지」 알림만 보내며, 주문ID는 그대로 유지됩니다.
  • 얼러트가 제대로 오는지만 확인하려면 테스트 모드를 켜세요. 주문 직전까지 확인하고 실제 주문은 보내지 않습니다.
  • 메모에 큰따옴표(")를 쓰지 마세요. 복사한 메시지에 메모가 그대로 들어가서 메시지 형식이 깨집니다.
NEW 트레이딩뷰 전략에 단축 주문메시지를 자동으로 연결해 주는 전략 변환 기능이 확장프로그램에 추가되었습니다. 코드를 직접 고치지 않아도 됩니다.

주문메시지 리스트에 등록하기

1.「메시지 작성」 화면에서 주문을 입력하고 ⑥ 메모에 주문 내용을 알아보기 쉽게 적습니다. 오른쪽 미리보기의 [+ 리스트에 저장] 을 누릅니다.

① 메모 ② [+ 리스트에 저장]

2.저장하면 주문ID가 자동으로 만들어지고 화면 아래 주문메시지 리스트에 추가됩니다.

① 저장 알림 ② 리스트에 추가된 주문 (주문ID는 「메모」 옆 주문ID 칸에 표시됩니다)

단축 주문메시지를 얼러트에 설정하기

3.리스트에서 메시지를 불러오면 미리보기에 [전체 메시지] 와 [단축 메시지] 복사 버튼이 나옵니다. 이 중 [단축 메시지] 를 눌러 복사합니다.

① [전체 메시지] ② [단축 메시지] — 단축 주문메시지를 복사합니다

단축 주문메시지 내용

TVM:{"orderid":"180f8d370b32e","memo":"바이낸스 현물 잔액대비 30% 매수","token":"인증키"}:MVT
token에는 등록된 인증키가 자동으로 들어갑니다. memo는 비워도 주문에는 지장이 없지만, 나중에 어떤 주문인지 알아보려면 꼭 적어 두세요.

4.주문이 많을 때는 리스트 위 검색창에 종목·메모·주문ID를 입력해 찾을 수 있습니다. 거래소 필터와 요약 칸으로도 목록을 좁힐 수 있습니다.

① 검색창에 주문ID(또는 종목·메모)를 입력 ② 해당 주문만 표시됩니다

5.지표·직접 만든 얼러트: 트레이딩뷰 얼러트의 「Message」 칸에 복사한 단축 주문메시지를 붙여넣습니다. 웹훅 URL 설정은 기존 방법과 같습니다. 여러개의 단축 주문메시지를 연결하여 설정하시면 순서대로 주문이 실행됩니다. 단, 거래소별로 1분에 실행할 수 있는 주문 수가 정해져 있습니다(TRIAL 1회, STANDARD는 구매 때 고른 10·15·20회). 단축 메시지 하나가 주문 1건으로 계산되므로 얼러트 하나에 같은 거래소 주문은 이 한도 이하로 넣어 주세요.

전략 변환으로 연결하기

전략 변환을 쓴 전략은 단축 메시지를 복사해 붙여넣지 않습니다. 대신 아래 순서로 설정합니다.

6.전략 설정의 「인증키」와 「롱 진입 주문ID」·「숏 진입 주문ID」 칸에 리스트의 주문ID를 입력합니다. 그러면 단축 주문메시지가 전략 코드에 연결됩니다.

① 인증키 ② 롱·숏 진입 주문ID ③ [Ok] — 주문ID는 주문메시지 리스트의 「주문ID」 칸에서 확인합니다

7.얼러트를 만들 때 「Message」 칸에는 {{strategy.order.alert_message}} 만 넣고 Webhook 알림을 설정합니다.

① 전략 선택 ② 메시지 ③ Webhook 알림 ④ [Create]

테스트 모드로 확인하기

새로 만든 얼러트나 전략이 제대로 동작하는지 실제 주문 없이 확인할 수 있습니다(v4.0.1부터). 테스트 모드인 주문메시지는 얼러트가 오면 인증키·주문메시지·API키 연결까지 확인하고, 거래소에 주문을 보내기 직전에 멈춥니다.

8.주문메시지 리스트에서 확인할 주문메시지를 오른쪽 클릭하고 「테스트 모드 켜기」를 누릅니다. 리스트의 메시지를 클릭해 불러온 뒤 오른쪽 미리보기 아래 「테스트」의 [테스트 모드 켜기] 버튼을 눌러도 됩니다.

① 주문메시지 행을 오른쪽 클릭 ② 「테스트 모드 켜기」

미리보기 아래 「테스트」의 [테스트 모드 켜기] — 리스트에서 메시지를 불러오기 전에는 누를 수 없습니다(그림은 불러오기 전)

9.확인창에서 대상·동작·적용 범위를 확인하고 [테스트 모드 켜기]를 누릅니다. 전략 변환에서 쓰는 주문메시지면 「함께」 줄에 사용 중인 전략도 보여 줍니다.

10.켜진 주문메시지는 「옵션」 칸 맨 앞에 테스트 모드 표시가 붙습니다.

11.얼러트가 오면 평소처럼 비활성·주문시간대·조건식·인증키·API키 연결을 먼저 확인하고, 모두 통과하면 주문 대신 텔레그램으로 「테스트 수신 (주문 안 함)」 알림이 옵니다. 검사를 통과하지 못하면 테스트 수신으로 기록되지 않고, 전략 변환에 연결한 주문메시지라면 「얼러트 수신」에 그 사유가 표시됩니다. 텔레그램 알림 여부는 사유에 따라 다릅니다(조건식 불일치·주문시간대 밖은 알림 없음). 전략 변환 목록의 「얼러트 수신」에도 테스트 수신 성공(주문 안 함)으로 표시됩니다.

12.확인이 끝나면 같은 메뉴에서 「테스트 모드 끄기」를 누릅니다. 다음 얼러트부터 실제로 주문합니다.

테스트 모드 유의사항
  • 주문ID로 온 얼러트(단축 주문메시지·전략 변환)에만 적용됩니다. 「전체 메시지 복사」로 붙여넣은 얼러트는 테스트 모드와 관계없이 주문합니다.
  • 주문 수량·잔고·포지션은 확인하지 않습니다. 실제 주문 처리까지 확인하려면 테스트넷을 쓰세요.
  • 같은 주문메시지(주문ID)를 쓰는 모든 얼러트에 적용됩니다.
  • 「API키 연결」 확인은 등록된 API키가 있고 연결이 허용(차단 안 됨)되어 있는지 보는 것입니다. 거래소에 접속해 키의 유효성·권한까지 확인하지는 않습니다.
  • 테스트 모드 설정은 서버에 저장되어 모든 PC가 같은 설정을 씁니다. 다른 PC의 화면에는 다시 조회할 때(화면에 들어오거나 돌아올 때) 반영되므로, 실제 주문 전에는 지금 화면의 상태를 확인하세요. 서버 상태를 확인하지 못하면 표시가 흐린 「테스트 모드?」로 바뀌고 켜고 끌 수 없습니다. 잠시 뒤 다시 확인해 주세요.
  • 확인이 끝나면 꼭 끄세요. 켜 둔 동안에는 얼러트가 와도 주문하지 않습니다.

주문메시지 관리

  • 무료 인증키도 주문메시지 리스트를 쓸 수 있습니다(20개까지, 유료 인증키는 600개까지).
  • 주문메시지 리스트는 서버에 저장되어 어느 PC에서나 같은 목록이 보입니다. 저장이 실패하면 닫힐 때까지 남는 에러가 뜨고 목록이 서버 내용으로 돌아가니, 확인 후 다시 시도해 주세요.
  • 전략 변환으로 전략에 연결한 주문메시지는 거래소 이름 옆에 표시가 붙고, 마우스를 올리면 어느 전략에서 쓰는지 보입니다. 이 주문메시지를 삭제하거나 비활성화하면 사용 중인 전략을 알려 주고 한 번 더 확인합니다.

이럴 때 특히 편리합니다

  • 주문 수량이나 레버리지를 자주 조정할 때: 주문메시지 리스트에서 내용만 수정하면 다음 얼러트부터 바로 반영됩니다.
  • 파인스크립트 전략의 alert_message 에 넣을 때: 메시지가 짧아 코드가 깔끔하고, 주문 내용을 바꿔도 스크립트를 수정할 필요가 없습니다. → 파인스크립트 전략을 사용하여 자동매매하는 방법
  • 여러 얼러트에서 같은 주문을 쓸 때: 한 곳만 수정하면 모든 얼러트에 적용됩니다.

이상으로 단축 주문메시지 작성방법을 알아보았습니다.

궁금한 사항이 있으시면 메일()로 문의를 해주세요.
