코인 주식 자동매매 시작하기

처음 사용하시는 분을 위한 가이드입니다. 확장프로그램의 「시작하기」 화면과 같은 순서로 설명합니다.

한국투자증권과 키움증권으로 국내 주식·미국 주식도 자동매매할 수 있습니다.

시작하기 전에
  • 트레이딩뷰 유료 요금제(Essential 이상)와 2단계 인증이 필요합니다. 웹훅 알림을 쓰기 때문입니다.
  • 만들 수 있는 얼러트 개수는 요금제마다 다릅니다 → 트레이딩뷰 요금제
  • 무료 인증키로 한 달 동안 테스트넷에서 써 볼 수 있습니다. 확장프로그램에서 바로 발행합니다.
    (무료 인증키로 쓸 API키는 IP 등록 없이 만들어 주세요)
유의사항
  • 주문메시지는 반드시 확장프로그램의 「메시지 작성」에서 만들어 주세요. 오류가 있으면 주문되지 않습니다.
  • 트레이딩뷰 점검이나 거래소 API 장애 때는 자동매매가 되지 않을 수 있습니다.
  • TVExtBot 사용 중 생긴 서비스 장애나 손해에 대해서는 책임을 지지 않습니다. 동의하는 경우에만 사용해 주세요.

한눈에 보는 순서

STEP 2~6은 확장프로그램 「시작하기」 화면의 체크리스트와 같습니다. 끝낸 단계는 자동으로 체크됩니다.

STEP
1

확장프로그램 설치

크롬 웹 스토어에서 TVExtBot 을 설치합니다.
STEP
2

인증키 등록

처음이라면 무료 인증키(테스트넷 한 달)로 시작하세요.
유료 인증키는 인증키 등록·구매 가이드 를 보세요.
STEP
3

거래소 API키 등록

거래소에서 API키를 발급받아 등록합니다 → 거래소 API 발급 방법
고정 IP가 필요한 거래소는 「API키 등록」 화면의 IP주소를 모두 등록하세요.
STEP
4

주문메시지 만들기

「메시지 작성」에서 매수·매도 메시지를 만들어 저장합니다.
STEP
5

트레이딩뷰 얼러트 연결

「전략 변환」으로 메시지를 연결하고 얼러트 1개를 만듭니다.
STEP
6

텔레그램 알림 (선택)

주문 결과와 에러를 텔레그램으로 바로 받습니다.

크롬확장프로그램 설치

1.크롬 웹 스토어에서 TVExtBot을 찾아 [Chrome에 추가] 를 누릅니다. chrome 웹 스토어로 바로가기

2.브라우저 오른쪽 위 확장프로그램 아이콘을 누르고, TVExtBot의 고정핀을 누릅니다.

3.TVExtBot 아이콘을 누르면 팝업이 열립니다. 팝업 오른쪽 위 설정을 누르면 설정 화면으로 갑니다.

4.처음 열면 「시작하기」 화면이 나옵니다. 위에서부터 순서대로 따라 하면 됩니다.

① 왼쪽 메뉴의 「시작하기」(배지는 진행 개수) ② 인증키 등록 ③ 거래소 API키 등록 ④ 주문메시지 만들기 ⑤ 트레이딩뷰 얼러트 연결 ⑥ 텔레그램 알림 연결(선택). 이 매뉴얼의 STEP 2~6과 같은 순서입니다.

왼쪽 메뉴는 자동매매(메시지 작성·전략 변환·퀵주문) / 기록(주문내역·에러 메시지) / 설정(API키 등록·인증키 등록·기본설정·기본정보)으로 나뉩니다. 설정을 마친 뒤 「시작하기 숨기기」로 메뉴에서 숨길 수 있고, 「기본정보」에서 다시 볼 수 있습니다.

인증키 발급 & 등록

5.「인증키 등록」 화면에서 인증키를 받습니다.

  • 무료 인증키: [무료 인증키 발행하기] → 이메일 입력 → [발행]. 메일로 인증키가 옵니다. (「시작하기」의 [무료 인증키 받기] 도 같습니다)
  • 유료 인증키: 화면 아래 구매표에서 고릅니다 → 인증키 등록·구매 가이드

계좌이체로 구매하려면 메일 또는 텔레그램으로 문의해 주세요.

① [무료 인증키 발행하기]를 누르면 이메일 입력창이 열립니다. 이메일을 넣고 [발행]을 누르세요

6.받은 메일의 이메일과 인증키를 「내 인증키」 칸에 붙여넣고 [인증하기] 를 누릅니다.
처음 등록할 때 「사용 전 확인해 주세요」 창이 뜨면 내용을 읽고 [위 내용에 동의하고 시작하기] 를 누릅니다.

① 이메일 ② 인증키를 붙여넣고 [인증하기]를 누르면 ③ 「인증을 완료하였습니다」 메시지가 뜹니다

거래소 API키 등록

사용할 수 있는 거래소
  • 빗썸 · 업비트
  • 바이빗 현물·선물(USD, USDT) · 바이낸스 현물·USDT선물·코인선물 · 비트겟 현물·USDT선물·코인선물
  • 페멕스 현물·선물 · OKX 현물·선물 · BingX(빙엑스) 선물
  • 한국투자증권 · 키움증권 (코스피·코스닥·나스닥·뉴욕·아멕스)
  • 테스트넷: 바이빗 · 바이낸스선물 · 비트겟 선물 · 페멕스 · OKX 현물·선물 · 키움증권 모의투자(국내주식)

거래소별 API 발급 방법은 [ 거래소 API 발급 방법 ]을 보세요.
고정 IP가 필요한 거래소는 「API키 등록」 화면 위 거래소에 등록할 IP주소를 모두 등록하세요.
웹훅 URL과 IP주소는 인증키 버전마다 다릅니다. 꼭 본인의 확장프로그램에 나온 값을 쓰세요.

7.「API키 등록」 화면에서 거래소 줄의 [+ 키 등록] 을 누릅니다. 줄 아래에 입력칸이 펼쳐지면 API키와 비밀키를 넣고 [저장] 을 누릅니다.

① 키를 등록할 거래소(Bybit) ② API키와 비밀키 ③ [저장] — 화면의 IP주소와 키는 가렸습니다

※ 인증키가 없으면 모든 거래소가 잠겨 있습니다(자물쇠). 무료 인증키는 테스트넷만 열립니다. 유료 거래소는 인증키 등록·구매 가이드를 보세요.

8.연결에 성공하면 “연결에 성공하였습니다” 메시지가 뜨고, 주문 허용 스위치가 켜집니다.

① 연결 성공 메시지 ② 「연결중」과 함께 켜진 주문 허용 스위치

※ 연결되지 않으면 API키·비밀키를 다시 확인하세요.
※ 주문 허용을 끄면 키는 남겨 둔 채 그 계정의 주문만 막습니다. 잠시 멈출 때는 삭제 대신 끄세요.
※ 이미 등록한 키를 고칠 때는 [편집] 을 누릅니다. 한 거래소에 계정을 여러 개 쓰려면 [계정 추가] 를 누릅니다.

주문메시지 작성

「메시지 작성」 화면에서 매수·매도 메시지 2개를 만들어 리스트에 저장합니다. 저장한 메시지는 다음 단계의 「전략 변환」에서 고릅니다.

유의사항
  • 한 거래소에서 1분에 실행할 수 있는 주문 수는 인증키마다 다릅니다(TRIAL 1회, STANDARD 구매 때 고른 10·15·20회). 넘는 주문은 무시되고, 1분 뒤 다시 정상 주문됩니다.

슈퍼트렌드 신호에 따라 롱이면 매수, 숏이면 매도하는 예제입니다. 공통 입력은 아래와 같습니다.

이 예제는 바이빗 실계정 기준이라 유료 인증키가 필요합니다. 무료 인증키로 연습하려면 거래소를 Bybit 선물 테스트넷으로 고르세요. 데모 계정은 교차 마진이라 레버리지 항목의 마진모드를 교차로 바꿔야 합니다(격리로 두면 주문이 거절됩니다). → 바이빗 테스트넷 사용법

  • 거래소 : Bybit 선물 · 계정 : 기본계정 · 종목 : BTC/USDT · 마켓 : USDT — 바이빗 USDT 선물은 양방향(헤지) 모드
  • 주문유형 : 시장가 · 주문수량 : 자산 대비 % → 잔액대비 30
  • 레버리지 : 1배(격리) · 「포지션 청산후 주문실행」 켬 — 반대 방향 포지션을 먼저 청산한 뒤 진입하므로 청산 메시지는 따로 필요 없습니다

9.매수 메시지 — 주문방법을 매수로 고르고, 「포지션 · 리스크 관리」에서 레버리지 1배(격리) 와 「포지션 청산후 주문실행」 스위치를 켭니다. [메시지 만들기] 로 확인한 뒤 메모에 「슈퍼트렌드 롱주문」을 적고 [+ 리스트에 저장] 을 누릅니다.

① 주문수량(자산 대비 %) ② 「포지션 청산후 주문실행」 스위치 ③ [메시지 만들기] ④ [+ 리스트에 저장]

10.매도 메시지 — 주문방법만 매도로 바꿉니다. 「포지션 청산후 주문실행」은 켠 채로 두고, 메모 「슈퍼트렌드 숏주문」을 적어 저장합니다.

① 주문수량(자산 대비 %) ② 「포지션 청산후 주문실행」 스위치 ③ [메시지 만들기] ④ [+ 리스트에 저장]

저장하기 전에 오른쪽 아래 「지금 바로 주문」으로 먼저 시험해 볼 수 있습니다(테스트넷 권장). 메시지를 직접 복사할 필요는 없습니다.

전략 변환 · 얼러트 설정

웹훅 URL은 인증키 버전마다 다릅니다. 「전략 변환」 3단계의 [웹훅URL 복사] 버튼으로 본인의 URL을 복사하세요.
※ 다른 버전의 웹훅 URL을 쓰면 주문 에러가 납니다.

「전략 변환」은 트레이딩뷰 전략(strategy) 코드에 주문메시지를 자동으로 연결해 줍니다. 코드를 직접 고치지 않고 얼러트도 하나만 만들면 됩니다.

11.아래 슈퍼트렌드 전략 코드를 복사합니다. (Pine Script v6, 롱·숏 반전 전략)
설명용 전략입니다. 실거래에는 쓰지 마세요.

//@version=6
strategy("슈퍼트렌드 전략", overlay = true,
     initial_capital   = 10000,
     default_qty_type  = strategy.percent_of_equity,
     default_qty_value = 10,
     commission_type   = strategy.commission.percent,
     commission_value  = 0.05,
     slippage          = 1)

atrPeriod = input.int(10, "ATR 기간", minval = 1)
factor    = input.float(3.0, "ATR 배수", minval = 0.1, step = 0.1)

[st, dir] = ta.supertrend(factor, atrPeriod)
plot(dir < 0 ? st : na, "상승 추세", color.green, style = plot.style_linebr)
plot(dir > 0 ? st : na, "하락 추세", color.red,   style = plot.style_linebr)

if ta.change(dir) < 0
    strategy.entry("Long", strategy.long)
if ta.change(dir) > 0
    strategy.entry("Short", strategy.short)

12.확장프로그램 왼쪽 메뉴의 「전략 변환」 에서 코드를 붙여넣고 [코드 확인] 을 누르면 「v6 — 바로 적용 가능」, 「진입 2 · 청산 0」, 「롱·숏(반전 전략)」으로 확인됩니다. [다음: 주문메시지 연결] 을 누릅니다. 롱 진입에는 「슈퍼트렌드 롱주문」, 숏 진입에는 「슈퍼트렌드 숏주문」을 고르고 [변환하기] → [코드 복사] 를 누른 뒤 [다음: 트레이딩뷰 설정] 을 누르면 아래 3단계 화면이 나옵니다.

① 롱 진입 ② 숏 진입에 저장한 메시지를 고르면 점검 칸에 ✓가 표시됩니다 ③ [변환하기]

① [인증키 복사] ② [웹훅URL 복사] — 이 화면의 안내 순서대로 진행합니다

13.트레이딩뷰 Pine 에디터에 변환한 코드를 붙여넣고 저장 → 차트에 추가(▷) 합니다.

① 변환한 코드를 붙여넣습니다 ② 차트에 추가(▷)

전략 설정(⚙) → Inputs 탭의 「TVExtBot」 그룹에서 인증키에 위의 [인증키 복사] 로 복사한 인증키를 붙여넣고 [Ok] 를 누릅니다. 주문ID는 연결한 메시지로 이미 채워져 있습니다.

① 인증키(가렸습니다) ② 롱·숏 진입 주문ID(자동 입력) ③ [Ok]

14.얼러트를 하나 만듭니다. 상단 Alert 를 눌러 Create alert 창을 열고 설정합니다.

  • Condition: 변환한 전략을 고릅니다. (지표가 아닙니다)
  • Message: 기본값 {{strategy.order.alert_message}} 를 그대로 둡니다.
  • Notifications → Webhook: 체크하고 [웹훅URL 복사] 로 복사한 URL을 붙여넣습니다.① 조건에서 전략 선택 ② 메시지 {{strategy.order.alert_message}} ③ 알림의 Webhook ④ [Create]

15.이제 시그널이 나오면 TVExtBot이 자동으로 주문합니다.
첫 주문이 들어오면 「시작하기」의 얼러트 단계가 자동으로 체크됩니다. 바로 체크하려면 [얼러트를 만들었어요] 를 누르세요.

① Alerts 목록에 새 얼러트가 Active 로 표시됩니다 (메시지는 {{strategy.order.alert_message}})

  • 익절·손절(strategy.exit)이 있는 전략은 청산 역할에도 청산 메시지를 연결합니다. 자세한 내용은 전략 변환 사용법을 보세요.
  • 전략이 아니라 지표(alertcondition)로 매매하려면 얼러트마다 주문메시지를 넣습니다. → 웹훅URL에 의한 자동매매
  • 전략 설정이나 코드를 바꾸면 얼러트를 다시 만들어야 합니다. 주문 내용(수량·레버리지)만 「메시지 작성」에서 바꾸는 것은 얼러트를 다시 만들지 않아도 바로 반영됩니다.

텔레그램 알림 연결 (선택)

16.주문 결과와 에러를 텔레그램으로 바로 받을 수 있습니다. 주문 실패를 놓치지 않도록 연결해 두기를 권합니다.
「기본설정」 → 텔레그램 개인 알림 카드의 [연결] 을 누르고, 열린 텔레그램 봇 대화창에서 시작합니다. 연결 상태가 연결됨으로 바뀌면 끝입니다.

※ 자세한 내용은 텔레그램 개인 알림봇 사용법을 보세요.

처음 설정 후 확인할 것

  • ☐ 「시작하기」 화면의 단계가 모두 체크되어 있다
  • ☐ 「API키 등록」에서 사용할 거래소의 주문 허용이 켜져 있다
  • ☐ 얼러트의 웹훅 URL이 본인 확장프로그램의 웹훅 URL과 같다
  • ☐ 주문메시지(매수·매도)를 「메시지 작성」에서 만들어 리스트에 저장했다
  • ☐ 텔레그램 연결 상태가 연결됨이다 (선택)
  • ☐ 실거래 전에 테스트넷이나 소액으로 주문을 확인했다 → 바이빗 테스트넷 사용법

주문이 들어가지 않으면 「에러 메시지」 화면의 이유와 해결 방법을 먼저 보고, 주문이 안 될 때 확인할 것을 순서대로 점검해 주세요.
