비트겟 현물·선물 자동매매 설정 방법 (트레이딩뷰 연동)

트레이딩뷰에서 만든 지표·전략의 신호로 비트겟 현물과 선물을 자동매매하는 방법입니다.
비트겟은 API키를 만들 때 정한 Passphrase 가 필요하니, 발급할 때 꼭 메모해 두세요.
비트겟 선물 테스트넷(데모트레이딩) 도 지원해서, 무료 인증키로 돈을 넣지 않고 먼저 연습해 볼 수 있습니다.

비트겟에서 할 수 있는 것

항목내용
현물 (bitget-spot)현물 매수·매도 — 수량, 잔액·총자산 대비 %, USDT 금액 기준 주문
선물 (bitget)USDT 선물, 코인 선물(USD) — 양방향 모드
선물 옵션레버리지, 마진모드, 목표가·손절가(발동가격), 추적손절매, 조건주문
테스트넷선물 bitget-testnet (비트겟 데모트레이딩)
통합계정(UTA)현물·선물 지원 — 선물은 USDT 무기한만 (코인 선물은 미지원) → 통합계정(UTA) 사용하기

설정 순서

  1. API키 발급: 프로필 → [API Keys] 에서 System-generated API Key 로 만들고, Passphrase를 정합니다. 사용할 거래 권한(현물·선물)을 켜고 출금 권한은 켜지 마세요. → 거래소 API 발급 방법
  2. API키 등록: 확장프로그램 API키 등록 화면의 비트겟 줄에 Passphrase(계정명 칸), API키, Secret키를 입력하고 [연결중] 을 확인합니다. 현물과 선물은 같은 API키를 함께 사용합니다.
    • 테스트넷은 비트겟을 데모트레이딩 모드로 바꾼 뒤 만든 데모 전용 API키를 Bitget-Testnet 줄에 등록합니다. → 테스트넷으로 연습하기
  3. 주문메시지 작성 → 얼러트 설정: 메시지 작성화면에서 메시지를 만들고, 트레이딩뷰 얼러트에 웹훅 URL과 함께 넣습니다. → 웹훅URL에 의한 자동매매

주문메시지 예시

잔액의 10%로 레버리지 5배 숏 진입 + 손절가 +2%

TVM:{"exchange":"bitget","account":"기본계정","symbol":"ETH/USDT","type":"market","side":"sell","bal_pct":10,"leverage":5,"margin_type":"isolated","sl_pct":2,"token":"인증키"}:MVT

숏 포지션 전량 시장가 청산

TVM:{"exchange":"bitget","account":"기본계정","symbol":"ETH/USDT","type":"market","side":"sell_close","token":"인증키"}:MVT

현물: 100 USDT어치 비트코인 시장가 매수

TVM:{"exchange":"bitget-spot","account":"기본계정","symbol":"BTC/USDT","type":"market","side":"buy","amount":100,"amount_type":"usdt","token":"인증키"}:MVT

테스트넷에서 잔액의 10%로 롱 진입

TVM:{"exchange":"bitget-testnet","account":"기본계정","symbol":"BTC/USDT","type":"market","side":"buy","bal_pct":10,"leverage":5,"margin_type":"isolated","token":"인증키"}:MVT

예시는 형식을 보여 드리기 위한 것입니다. 실제 메시지는 반드시 확장프로그램의 메시지 작성화면에서 만들어 주세요. 각 항목의 뜻은 주문메시지 항목 설명에 있습니다.

통합계정(UTA) 사용하기

비트겟 계정을 통합계정(UTA, Unified Trading Account) 으로 전환했어도 TVExtBot으로 현물과 선물 자동매매를 할 수 있습니다.

  • 설정은 클래식 계정과 같습니다. 통합계정에서 만든 API키를 확장프로그램의 같은 비트겟 줄(테스트넷은 Bitget-Testnet 줄)에 등록하고, 거래소도 그대로 선물은 bitget(테스트넷 bitget-testnet), 현물은 bitget-spot 으로 주문메시지를 만듭니다.
  • 서버가 API키를 보고 클래식 계정인지 통합계정인지 자동으로 구분해서 주문하므로, 따로 선택할 것이 없습니다.
  • 선물은 클래식 계정과 같이 양방향(헤지) 모드로 동작하고, 레버리지·마진모드·목표가·손절가·추적손절매·조건주문을 쓸 수 있습니다.
  • 현물은 클래식 계정과 같은 방법(수량, 잔액·총자산 대비 %, USDT 금액 기준)으로 매수·매도합니다.
  • 통합계정은 현물과 선물이 자산을 함께 씁니다. 텔레그램 보유자산 조회에서도 현물·선물을 나누지 않고 “Bitget 통합계정"으로 한 번만 보여 줍니다.
통합계정에서 아직 안 되는 것
  • USDT 무기한 선물만 지원합니다. 코인 선물(USD 마켓)은 주문할 수 없습니다.
  • 통합계정의 추적손절매는 포지션과 별도의 주문으로 걸립니다. TVExtBot으로 청산해서 그 종목의 포지션이 모두 없어지면 함께 취소됩니다. 반대 방향 포지션이 남아 있거나 거래소 화면에서 직접 청산했다면 남은 추적손절매 주문을 직접 취소해 주세요.

테스트넷으로 연습하기

비트겟의 테스트넷은 데모트레이딩입니다. 실제 계정과 같은 화면에서 가상 자금으로 주문하며, TVExtBot에서는 거래소 Bitget 선물 테스트넷(bitget-testnet)으로 사용합니다.

  1. 비트겟에 로그인한 뒤 화면의 데모트레이딩(Demo Trading) 으로 전환합니다.
  2. 데모트레이딩 모드에서 API 관리로 들어가 데모용 API키를 만듭니다. 실전 API키와 같이 Passphrase를 정하고, 무료 인증키로 쓸 때는 IP 등록 없이 만들어 주세요.
  3. 확장프로그램 API키 등록 화면의 Bitget-Testnet 줄에 Passphrase(계정명 칸), API키, Secret키를 입력하고 [연결중] 을 확인합니다.
  4. 퀵주문에서 거래소를 Bitget 선물 테스트넷으로 고르고 [보유자산보기] 로 데모 자금이 보이는지 확인합니다.
  5. 메시지 작성화면에서 거래소를 Bitget 선물 테스트넷으로 골라 주문메시지를 만들고, 얼러트에 넣어 자동매매를 확인합니다.

종목은 실전과 같은 이름(BTC/USDT 등)을 씁니다. 실전에서 쓰던 주문메시지는 exchange 만 바꿔 넣지 말고, 테스트넷용으로 새로 만들어 주세요.

주의사항

  • 현물은 청산이 없으므로 매도(sell)로 보유 코인을 팝니다. 레버리지·목표가·손절가 같은 선물 옵션은 쓸 수 없습니다.
  • 선물은 양방향 모드로 동작하므로 롱 청산은 buy_close, 숏 청산은 sell_close 를 씁니다. 리듀스 온리는 쓸 수 없습니다.
  • 목표가·손절가의 지정가격(tp_lo_*, sl_lo_*)은 쓸 수 없습니다. 발동가격에 닿으면 시장가로 청산합니다.
  • 추적손절매 콜백 비율은 1 ~ 10% 입니다.
  • 카피 트레이딩 대상 코인은 100% 수량 시장가 청산만 가능합니다. (지정가 청산·부분 청산 미지원)
  • Passphrase는 나중에 확인하거나 바꿀 수 없어서, 잊어버리면 API키를 지우고 새로 만들어야 합니다.
  • 실전 API키와 데모 API키는 서로 다릅니다. 실전 키는 Bitget 줄에, 데모 키는 Bitget-Testnet 줄에 등록해 주세요. 바꿔 넣으면 연결되지 않습니다.

자주 묻는 질문

Q. 숏 진입 때 손절가는 왜 플러스(+) 값인가요?
숏은 가격이 올라야 손실이 나므로, 손절가는 주문가격보다 위(+), 목표가는 아래(−) 로 넣습니다.

Q. 비트겟도 테스트넷으로 연습할 수 있나요?
네. 비트겟 데모트레이딩을 Bitget 선물 테스트넷으로 지원합니다. 무료 인증키로도 사용할 수 있습니다. → 테스트넷으로 연습하기

Q. 통합계정(UTA)으로 전환했는데 그대로 써도 되나요?
네. 통합계정에서 만든 API키를 같은 비트겟 줄에 등록하면 됩니다. 현물과 USDT 무기한 선물을 지원하고, 코인 선물은 아직 지원하지 않습니다. → 통합계정(UTA) 사용하기

Q. 비트겟 수수료를 줄일 수 있나요?
추천인 링크로 가입하면 수수료 할인을 받을 수 있습니다. → 거래소 수수료 할인링크
