TVExtBot

2026년 10월 4일 일요일

텔레그램 컨트롤 센터 사용법 (자산·포지션 조회, 미체결 취소, 포지션 청산, API 연결/차단)

TVExtBot 컨트롤 센터는 텔레그램에서 자산·포지션·미체결 주문을 확인하고, 주문 취소·포지션 청산·API 연결/차단을 할 수 있는 봇입니다.
외출 중에도 스마트폰으로 확인하고, 급할 때는 자동매매를 한 번에 멈출 수 있습니다.

할 수 있는 것

메뉴명령어기능
📊 총자산/total모든 거래소 자산과 합계
📈 포지션/positions선물 포지션 조회, 포지션 청산
📋 미체결/orders미체결 주문 조회, 계정별 취소
💰 거래소별 잔고/balance거래소별 코인·종목 잔고
🔌 API 관리/control_api계정별 연결상태 확인, 연결/차단
🔁 전체 차단/연결/control_all모든 계정을 한 번에 차단/연결
🔓 연결 해제/unlink이 텔레그램의 연결 해제
☰ 전체 메뉴/menu모든 기능 보기
❓ 사용법/help사용법 안내, 고정 메뉴 다시 표시
▶️ 시작/start연결상태 확인

주문·에러 알림은 개인 알림봇(@TTVExtBot)으로 받습니다.
체험판 인증키로는 사용할 수 없습니다.

시작하기

1.먼저 확장프로그램에서 텔레그램 알림봇을 연결합니다. (텔레그램 개인 알림봇 사용법) 컨트롤 센터는 따로 등록하지 않아도 같은 텔레그램으로 바로 사용할 수 있습니다.

2.QR코드를 찍거나 링크를 눌러 컨트롤 센터를 엽니다.
https://t.me/iTVExtBot

3.처음 열면 아래와 같은 소개 화면이 나옵니다. [시작] 을 누르고, 본인 메일이 표시되면 준비 완료입니다.

「연결된 계정이 없습니다」가 나오면 확장프로그램에서 텔레그램 [연결]을 누른 뒤 /start 를 다시 보내 주세요.

메뉴 사용법

입력창 아래에 고정 메뉴가 항상 표시됩니다.

📊 총자산📈 포지션
📋 미체결🔌 API 관리
☰ 전체 메뉴
  • 나머지 기능은 [☰ 전체 메뉴] 에 있습니다.
  • 입력창에 / 를 입력해도 전체 명령어 목록이 나옵니다.
  • 메뉴가 사라졌으면 /help 를 보내세요.
  • [🔄 새로고침] 을 누르면 다시 조회합니다.

인증키가 여러 개 연결되어 있으면 먼저 메일을 고릅니다.

📊 총자산

모든 거래소의 자산과 합계를 보여 줍니다.

  • 합계는 단위(USDT, KRW 등)별로 냅니다.
  • 차단중인 계정도 포함되며 🔒 가 붙습니다.
  • 조회하지 못한 계정은 사유가 함께 표시됩니다.

📈 포지션

모든 거래소의 선물 포지션을 보여 줍니다.

  • 방향(▲ 롱 / ▼ 숏), 수량, 진입가, 현재가, 청산가, 손익이 표시됩니다.
  • 청산가까지 10% 이내면 🚨 경고가 붙습니다.

포지션 청산

청산을 허용하면 포지션마다 [✖ 청산] 버튼이 나옵니다.

  1. 청산할 포지션의 [✖ 청산] 을 누릅니다.
  2. [✖ 청산 실행] 을 누르면 시장가로 전량 청산합니다.
  3. 청산 후 다시 조회해서 결과를 알려 줍니다. 실패하면 사유와 남은 포지션이 표시됩니다.
  • 실행 내역은 메일로도 보내 드립니다.
  • 확인 버튼은 60초 동안만 유효합니다.
  • 지원: 바이낸스 선물, 바이빗, 비트겟, OKX, BingX, Phemex

청산 허용 설정

청산은 기본으로 꺼져 있습니다. 확장프로그램 기본설정 > 텔레그램 개인 알림봇 설정에서 「텔레그램 컨트롤 센터(@iTVExtBot)에서 포지션 청산 허용」 을 체크하면 켜집니다.

허용하면 텔레그램만으로 청산할 수 있습니다. 텔레그램 2단계 인증을 꼭 설정하세요. (설정 > 개인정보 및 보안 > 2단계 인증)

📋 미체결

모든 거래소의 미체결 주문을 보여 줍니다. 지정가, 조건부, 익절·손절, 트레일링 주문이 모두 포함됩니다.

  • 지원: 바이낸스(현물·선물), 바이빗, 비트겟, 업비트, OKX, BingX

미체결 주문 취소

  1. 계정별 [✖ N건 취소] 를 누릅니다.
  2. [✖ 전부 취소] 를 누르면 그 계정의 미체결 주문을 모두 취소합니다.
  3. 취소 결과가 표시됩니다.
  • 포지션은 그대로 남습니다.
  • 실행 내역은 메일로도 보내 드립니다.
  • 확인 버튼은 60초 동안만 유효합니다.

💰 거래소별 잔고

[☰ 전체 메뉴] > 💰 거래소별 잔고에서 거래소를 고르면, 계정별 코인·종목 잔고를 보여 줍니다.

  • 지원: 빗썸, 업비트, 바이빗, 바이낸스, 비트겟, Phemex, OKX, BingX, 한국투자증권, 키움증권
  • 현물과 선물을 한 번에 조회합니다.
  • 해외주식 금액은 한국투자증권은 원화, 키움증권은 USD로 표시됩니다.

🔌 API 관리

모든 계정의 연결상태를 보여 줍니다. (🟢 연결중 · 🔴 차단중)

  • 계정 버튼을 누르면 연결/차단이 바뀝니다. 연결은 한 번 더 확인합니다.
  • 차단된 계정은 얼러트가 와도 주문하지 않습니다.
  • [🚨 전부 차단] 으로 모든 계정을 바로 차단할 수 있습니다.

🔁 전체 차단/연결

자동매매를 당장 모두 멈춰야 할 때 사용합니다.

  1. [☰ 전체 메뉴] > 🔁 전체 차단/연결에서 [🚨 전부 차단] 또는 [✅ 전부 연결] 을 고릅니다.
  2. 대상 계정을 확인하고 실행합니다.
  3. 계정별 결과가 표시됩니다.

전부 연결은 일부러 차단해 둔 계정도 연결하고, 바로 자동매매가 시작됩니다.
테스트넷·모의투자 계정은 대상에서 빠집니다.

자주 묻는 질문

Q. 급락장에서 모두 정리하려면?
① [🔌 API 관리] > [🚨 전부 차단] 으로 새 주문을 막고 → ② [📋 미체결] 에서 주문을 취소하고 → ③ [📈 포지션] 에서 청산합니다.

Q. 차단하면 포지션과 미체결 주문도 정리되나요?
아니요. 차단은 이후 주문만 막습니다. 주문은 미체결 취소, 포지션은 포지션 청산으로 정리하세요.

Q. 청산 버튼이 보이지 않아요.
청산 허용을 켜야 나타납니다. 켜져 있다면 청산을 지원하지 않는 거래소입니다.

Q. 하지 않은 취소·청산 메일을 받았어요.
바로 확장프로그램에서 텔레그램 연결을 해제하고, 거래소 API 키를 바꿔 주세요.

Q. 알림봇(@TTVExtBot)과 무엇이 다른가요?
알림봇은 알림을 받는 봇, 컨트롤 센터는 조회·취소·청산을 하는 봇입니다.

Q. 다른 텔레그램으로 바꾸고 싶어요.
새 텔레그램에서 알림봇 연결을 다시 하면 컨트롤 센터도 함께 바뀝니다.
