한국투자증권 주식 자동매매 설정 방법 (국내·미국 주식, 트레이딩뷰 연동)

트레이딩뷰에서 만든 지표·전략의 신호로 한국투자증권 계좌의 국내·미국 주식을 자동매매하는 방법입니다.
코인과 같은 방식(트레이딩뷰 얼러트 → TVExtBot → 증권사)으로 동작합니다.

한국투자증권에서 할 수 있는 것

항목내용
국내 주식코스피(KOSPI), 코스닥(KOSDAQ) — 시장가·지정가
미국 주식나스닥(NASD), 뉴욕(NYSE), 아멕스(AMEX) — 지정가만
주문수량주식 수, 잔액·총자산 대비 %

설정 순서

  1. Open API 신청: 한국투자증권 홈페이지 [서비스신청] → [Open API] → [KIS Developers]에서 신청하고 APP Key와 APP Secret을 받습니다. → 거래소 API 발급 방법
  2. API키 등록: 확장프로그램 API키 등록 화면의 KIS 줄에서 계정명 칸에 계좌번호(숫자 10자리), APP Key, APP Secret 순으로 입력합니다.
  3. 종목 선택: API키를 등록하면 메시지 작성화면에서 종목을 고를 수 있습니다.
  4. 주문메시지 작성 → 얼러트 설정: 메시지를 만들어 트레이딩뷰 얼러트에 웹훅 URL과 함께 넣습니다. → 웹훅URL에 의한 자동매매

주문메시지 예시

삼성전자 10주 시장가 매수

TVM:{"exchange":"kis","account":"계좌번호","symbol":"005930/KOSPI","type":"market","side":"buy","amount":10,"token":"인증키"}:MVT

애플 5주를 마지막 체결가로 지정가 매수 (미국 주식)

TVM:{"exchange":"kis","account":"계좌번호","symbol":"AAPL/NASD","type":"limit","side":"buy","amount":5,"price":"last","token":"인증키"}:MVT

종목은 종목코드/시장 형식입니다. 예시는 형식을 보여 드리기 위한 것이니, 실제 메시지는 반드시 메시지 작성화면에서 만들어 주세요. 각 항목의 뜻은 주문메시지 항목 설명에 있습니다.

주의사항

  • 미국 주식은 지정가 주문만 가능하며, 주문가격에 BID·ASK는 선택할 수 없습니다.
  • 주문은 해당 시장의 거래 시간에만 체결됩니다. 장이 열리지 않은 시간의 얼러트는 주문되지 않을 수 있습니다.
  • API키 등록 시 계정명에는 반드시 계좌번호를 입력해야 합니다. (예: 50071022-01 또는 5007102201)
  • 모의투자 계좌는 지원하지 않습니다. 처음에는 소량으로 주문이 들어가는지 확인해 주세요.

자주 묻는 질문

Q. 트레이딩뷰에서 국내 주식 차트로 얼러트를 만들 수 있나요?
네. 트레이딩뷰에서 해당 종목 차트에 지표·전략을 넣고 얼러트를 만들면 됩니다. 주문메시지의 종목은 TVExtBot 작성화면에서 고른 종목으로 주문됩니다.

Q. 주식 투자에도 파인스크립트 전략을 쓸 수 있나요?
네. 전략 만드는 방법은 파인스크립트 강좌에서 예제와 함께 설명합니다.
