TVExtBot 옵티마이저 사용법: 트레이딩뷰 전략 설정값 자동 백테스트

TVExtBot 옵티마이저는 트레이딩뷰 전략의 설정값(인풋)을 정해진 범위에서 하나씩 바꿔 가며 자동으로 백테스트하고, 조합마다 순익·승률·최대손실폭을 보고서로 정리해 주는 크롬 확장프로그램입니다.
설정 창을 열고 값을 바꾸고 결과를 옮겨 적는 반복 작업을 대신해 줍니다.

이런 분께 추천합니다
  • 공개 전략이나 직접 만든 전략의 최적 설정값을 찾고 싶은 분
  • ATR 기간·배수, 이동평균 길이, 손절 % 같은 값을 여러 조합으로 비교하고 싶은 분
  • 백테스트 결과를 CSV로 내려받아 엑셀 등에서 분석하고 싶은 분

1. 설치하기

  1. 크롬 웹 스토어에서 TVExtBot 옵티마이저를 설치합니다.
    TVExtBot 옵티마이저 설치하기
  2. 브라우저 오른쪽 위의 확장프로그램 아이콘에서 TVExtBot 옵티마이저를 고정(핀)해 두면 편리합니다.
무료 사용과 인증키 등록
  • 인증키 없이도 최대 2개 항목까지 최적화할 수 있습니다.
  • 옵티마이저의 인증키등록 탭에 TVExtBot 인증키(이메일·인증키)를 등록하면 최대 8개 항목까지 한 번에 최적화할 수 있습니다. → 인증키 등록&구매가이드

2. 트레이딩뷰 준비하기

옵티마이저는 트레이딩뷰 화면을 직접 조작하므로, 시작 전에 아래 두 창이 열려 있어야 합니다.

  1. 트레이딩뷰 차트에 최적화할 전략(strategy) 을 추가하고, 종목과 시간봉을 선택합니다.
  2. 차트 아래 전략 테스터를 열고 오버뷰(Overview) 탭을 선택합니다.
  3. 전략 이름 옆의 설정(⚙) 을 눌러 인풋(Inputs) 탭을 열어 둡니다.

전략 테스터의 오버뷰 탭과 전략의 인풋 창이 열려 있지 않으면 최적화가 시작되지 않습니다.

지표(indicator)는 백테스트가 되지 않으므로 옵티마이저를 쓸 수 없습니다. 지표라면 먼저 전략으로 바꿔 주세요.

3. 최적화할 항목 입력하기

  1. 옵티마이저 아이콘을 눌러 메인 탭을 엽니다.
  2. [넘버링] 버튼을 누르면 전략 인풋 창의 숫자 항목 옆에 번호가 표시됩니다.
  3. 최적화할 항목마다 아래 값을 입력합니다.
입력값의미예 (ATR 기간)
항목번호넘버링으로 표시된 번호1
시작값 → 종료값테스트할 범위5 → 20
스텝값한 번에 증가시킬 간격1
  1. 항목을 더 넣으려면 [항목 추가] 를 누릅니다.
입력할 때 주의할 점
  • 번호는 숫자 입력 항목에만 붙습니다. 체크박스나 목록 선택 항목은 최적화할 수 없습니다.
  • 시작값은 종료값보다 작아야 하고, 스텝값은 0보다 커야 합니다.
  • 같은 항목번호를 두 번 넣을 수 없습니다.
  • 스텝값은 해당 인풋의 증가 간격(화살표를 눌렀을 때 바뀌는 최소 간격) 이상으로 넣어 주세요. 예를 들어 0.5 단위로 바뀌는 인풋에 0.1을 넣으면 의도대로 바뀌지 않습니다.

4. 최적화 실행하기

  1. [최적화] 버튼을 누르면 옵티마이저가 인풋값을 바꾸고 → 확인을 누르고 → 전략 테스터 결과를 읽는 과정을 모든 조합에 대해 반복합니다.
  2. 끝나면 “최적화가 성공적으로 완료되어 보고서에 추가되었습니다.” 알림이 표시됩니다.
  3. 도중에 멈추려면 [중지] 를 누릅니다. 중지하기 전까지의 결과는 보고서에 저장됩니다.
실행 중에는
  • 옵티마이저가 화면을 직접 조작하므로, 실행 중에는 트레이딩뷰 탭을 그대로 두고 마우스·키보드로 조작하지 마세요. 다른 탭으로 옮기거나 창을 최소화하면 멈추거나 느려질 수 있습니다.
  • 조합 수는 각 항목의 값 개수를 곱한 수입니다. 예: 5~20(스텝 1) × 1~5(스텝 0.5) = 16 × 9 = 144번 백테스트. 조합마다 결과를 기다리므로 조합이 많으면 시간이 오래 걸립니다.
  • 처음에는 넓은 범위와 큰 스텝으로 대략 좋은 구간을 찾고, 그 구간만 좁혀서 다시 돌리면 시간을 크게 줄일 수 있습니다.
  • 트레이딩뷰의 딥 백테스팅을 켠 경우에도 결과 업데이트를 자동으로 눌러 진행합니다.

5. 보고서 확인하기

  1. 옵티마이저의 보고서 탭에서 [새로고침] 을 누르면 최적화 기록이 표시됩니다. (전략명, 날짜, 거래소, 종목, 캔들, 인풋 범위, 최대순익)
  2. [보고서] 버튼을 누르면 새 탭에서 조합별 상세 결과가 열립니다.
항목의미
인풋값테스트한 설정값 조합
순익금 / 순익률순이익 금액과 비율
총 거래청산된 거래 수
승률수익 거래 비율
수익지수총수익 ÷ 총손실 (Profit Factor)
최대손실폭 / 최대손실률최대 낙폭(MDD) 금액과 비율
평균거래량 / 평균거래율거래당 평균 손익
거래시 평균봉수한 거래를 보유한 평균 봉 수
  • 각 열 제목을 누르면 정렬할 수 있습니다. 순익뿐 아니라 승률·최대손실률로도 정렬해 비교해 보세요.
  • [다운로드] 를 누르면 결과를 CSV 파일로 저장합니다.
  • 보고서는 브라우저(옵티마이저 확장프로그램)에 저장됩니다. 확장프로그램을 삭제하면 보고서도 사라지니 필요한 결과는 CSV로 받아 두세요.

6. 결과를 전략에 적용하기

  1. 보고서에서 고른 조합을 전략의 인풋 창에 직접 입력하고 확인을 누릅니다.
  2. 전략 테스터에서 결과가 보고서와 같은지 확인합니다.
  3. 다른 기간이나 다른 종목에서도 결과가 크게 무너지지 않는지 확인합니다.
  4. 확인한 설정으로 얼러트를 새로 만들어 자동매매에 연결합니다. (얼러트는 만든 시점의 설정으로 동작합니다) → 파인스크립트 전략을 사용하여 자동매매하는 방법
순익 1위 조합을 그대로 쓰지 마세요

과거 데이터에 가장 잘 맞춘 값은 미래에는 맞지 않을 수 있습니다(과최적화). 아래 기준을 함께 보세요.

  • 주변 값(한 스텝 위아래)도 결과가 좋은 안정된 구간인가
  • 총 거래 수가 충분한가 (수십 회 이하는 우연일 가능성이 큼)
  • 최대손실률을 실제로 견딜 수 있는가

자세한 내용은 최적화가 잘 되는 input 설계법과 백테스트와 실전이 다른 이유를 참고해 주세요.

7. 문제가 생겼을 때

메시지해결 방법
트레이딩뷰 사이트의 전략에서 인풋창을 열어 주세요.전략 설정(⚙)의 인풋 탭을 연 상태에서 다시 실행합니다.
항목번호가 존재하지 않습니다.[넘버링]을 다시 눌러 표시된 번호로 고칩니다.
입력값 범위에서 ‘시작’은 ‘종료’보다 작아야 합니다.시작값 < 종료값, 스텝값 > 0 인지 확인합니다.
항목번호에 중복되는 값은 입력할수 없습니다.같은 번호가 두 번 들어가지 않았는지 확인합니다.
입력값에 오류가 있습니다.비어 있는 칸이 없는지, 숫자만 입력했는지 확인합니다.
항목을 추가할수 없습니다.무료는 최대 2개, 인증키 등록 시 최대 8개까지입니다.
