바이빗 테스트넷(데모트레이딩) 사용법

테스트넷은 거래소가 제공하는 모의 투자 환경입니다. 실제 돈 대신 가상 자금으로 주문하므로, 새 전략이나 주문메시지를 실거래 전에 안전하게 확인할 수 있습니다.
바이빗의 테스트넷은 데모트레이딩입니다. 따로 가입할 필요 없이 바이빗 계정에서 데모트레이딩 모드로 전환해서 사용합니다.
TVExtBot의 무료(TRIAL) 인증키는 테스트넷에서 한 달간 무료로 사용할 수 있습니다.

예전 바이빗 테스트넷(testnet.bybit.com) 키는 사용할 수 없습니다

바이빗 테스트넷 사이트가 접속 지역 제한으로 주문이 되지 않아, TVExtBot은 데모트레이딩으로 바뀌었습니다. 예전 테스트넷에서 만든 API키를 등록해 두었다면, 아래 순서대로 데모용 API키를 새로 만들어 Bybit-Testnet 줄에 다시 등록해 주세요. 예전 키로 주문하면 「바이빗 테스트넷이 데모트레이딩으로 바뀌어…」 안내가 표시됩니다.

데모트레이딩으로 전환

1.바이빗 에 로그인한 뒤, 위쪽 메뉴의 ① Trade → ② Demo Trading 을 클릭합니다.

바이빗 계정이 없다면 먼저 가입해 주세요. 데모트레이딩은 실제 계정과 같은 화면에서 가상 자금으로만 거래합니다.

2.왼쪽 위에 Demo Trading 표시가 나오면 데모트레이딩 모드입니다. ① Assets → ② Unified Trading Account 에서 ③ 데모 자금(USDT) 을 확인합니다.

데모 자금이 0이면 주문이 「잔고 부족」으로 실패합니다. 먼저 USDT가 있는지 확인해 주세요. 데모 계정은 교차 마진(Cross Margin) 으로 표시됩니다.

데모용 API키 발급

3.데모트레이딩 모드인 상태에서 오른쪽 위 프로필 아이콘 → API 의 API 관리화면에서 ①「Create New Key」 를 클릭하고 ②「System-generated API Keys」 를 선택합니다.

실거래 모드에서 만든 API키는 데모트레이딩에서 쓸 수 없습니다. 반드시 왼쪽 위에 Demo Trading이 표시된 상태에서 만들어 주세요.

4.아래 그림의 ①~⑦ 순서대로 입력한 후 「Submit」을 클릭합니다.

① API Transaction 선택 → ② API키 이름 입력(아무 이름이나 OK) → ③ Read-Write → ④ No IP restriction → ⑤ Unified Trading 체크 → ⑥ Assets 체크 → ⑦ Submit

5.① API키(API Key) 와 ② 비밀키(API Secret) 가 표시됩니다. 「Copy」로 복사해 메모해 둔 뒤 ③「Understood」 를 누릅니다.

비밀키는 이 화면을 닫으면 다시 볼 수 없습니다.

6.API 관리화면에 새로 만든 데모용 API키가 추가됩니다.

IP를 등록하지 않은 API키는 3개월 동안 사용할 수 있습니다. 기간이 지나면 같은 방법으로 새로 만들어 다시 등록해 주세요.

API키 등록

7.확장프로그램의 API키 등록 화면에서 Bybit-Testnet 줄에 위에서 복사한 ① API키 와 ② 비밀키 를 입력하고 저장합니다. 계정명은 자유롭게 정하면 됩니다.

문제없이 연결되면 [[Bybit-Testnet] 연결에 성공하였습니다.]라는 메시지가 표시되고 ③ [연결중] 으로 바뀝니다.

8.퀵주문에서 ① Bybit 선물 테스트넷을 선택한 후 ② [보유자산보기] 버튼을 클릭하면 ③ 데모 자금이 조회됩니다.

퀵주문으로 매수·청산이 되는지 확인해 보세요. 주문 내역은 바이빗 데모트레이딩 화면에서 볼 수 있습니다.

테스트넷으로 자동매매 확인하기

9.확장프로그램의 메시지 작성화면에서 거래소를 Bybit 선물 테스트넷(또는 Bybit 현물 테스트넷)으로 선택해 주문메시지를 만듭니다.

10.트레이딩뷰에서 얼러트를 만들고, 주문메시지와 웹훅 URL을 설정합니다. 방법은 실거래와 같습니다. → 웹훅URL에 의한 자동매매

11.얼러트가 울리면 바이빗 데모트레이딩 화면의 주문 내역과 텔레그램 알림으로 주문이 제대로 들어갔는지 확인합니다.

주의사항

  • 실거래 API키와 데모 API키는 서로 다릅니다. 실거래 키는 Bybit 줄에, 데모 키는 Bybit-Testnet 줄에 등록해 주세요. 바꿔 넣으면 연결되지 않습니다.
  • 데모트레이딩도 실거래와 같은 종목(BTC/USDT, SUI/USDT 등)을 거래할 수 있습니다.
  • 데모 계정은 통합계정(UTA), 교차 마진 입니다. 주문메시지의 마진모드를 교차로 설정해 주세요. 격리로 주문하면 「격리마진 모드에서만 가능합니다」 안내가 표시됩니다.
  • IP를 등록하지 않은 데모 API키는 3개월 후 만료됩니다. 만료되면 새로 만들어 다시 등록해 주세요.
  • 데모트레이딩은 체결 가격·수수료가 실거래와 조금 다를 수 있습니다. 주문이 의도대로 들어가는지 확인하는 용도로 사용해 주세요.
실거래로 옮기기 전에 확인할 것
  • 매수·매도·청산 주문이 모두 의도한 대로 들어갔다
  • 주문 수량(잔액 대비 %)과 레버리지가 예상과 같다
  • 여러 번의 신호에서도 포지션이 꼬이지 않았다 (예: 청산 없이 반대 진입)
  • 실거래용 주문메시지는 거래소를 실거래 거래소로 바꿔 새로 만들고, 얼러트도 새 메시지로 다시 설정한다
공유하기:

함께 보면 좋은 글

  • 5분 만에 첫 자동매매 따라 하기 (무료 테스트넷)
  • 키움증권 주식 자동매매 설정 방법 (국내·미국 주식, 트레이딩뷰 연동)
  • OKX 선물 자동매매 설정 방법 (트레이딩뷰 연동)
  • 바이낸스 선물·현물 자동매매 설정 방법 (트레이딩뷰 연동)
